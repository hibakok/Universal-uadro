Universal uadro
Инфраструктура «всё из кирпичиков»: собственный язык программирования uadro,растущий с двоичного кода вверх, виртуальный процессор (UVM) с ОЗУ и всё,что на них будет построено.

Что здесь
Универсальный бустрап: опкоды → ассемблер (uAsm) → кирпичный язык (uBrick) →язык высокого уровня (uLang).
Виртуальная машина UVM со своей спецификацией, не привязанная к существующимархитектурам.
Самоописание: любой агент (ИИ или человек) может войти в проект и продолжитьего, не читая репозиторий целиком.
Карта входа (читать по порядку)
CHARTER.md — конституция проекта: неизменные правила.
ROADMAP.md — этапы, критерии готовности, текущий статус.
DOC/ARCHITECTURE.md — слои и ветви кода.
DOC/CONVENTIONS.md — формат карточек методов и соглашения.
DOC/CONTINUE.md — протокол продолжения работы (для ИИ и людей).
SPEC/ — спецификации слоёв; registry/METHODS.md — реестр всех методов.
Правила (кратко)
Один метод — одна простая функция; сложное собирается из простых.
Любой файл ≤ 500 строк (проверяет CI).
Каждый метод описан карточкой @method (вход / выход / функция).
Сторонние библиотеки запрещены.
Каждая правка оставляет репозиторий работоспособным, CI — зелёным.
Статус
Единственный источник статуса — ROADMAP.md (раздел «Где мы сейчас»).

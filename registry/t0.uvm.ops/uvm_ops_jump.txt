КАРТОЧКИ ФАЙЛА tools/uvm_ops_jump.py

Ветвь: t0.uvm.ops
Слой: T0
Методов: 6
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Обработчики опкодов группы «переходы и остановка»: JMP, JZ,
          JNZ, CALL, RET, HALT (SPEC/L0-UVM.txt, разделы 4-5).

МЕТОД op_jmp(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — абсолютный адрес байта в ОЗУ
  выход:       нет
  функция:     JMP addr ( — ): PC = addr.

МЕТОД op_jz(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — абсолютный адрес байта в ОЗУ
  выход:       нет
  функция:     JZ addr ( c — ): PC = addr, если c = 0; условие снимается
               со стека в любом случае; пустой стек — ловушка 2.
  зависимости: ds_pop

МЕТОД op_jnz(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — абсолютный адрес байта в ОЗУ
  выход:       нет
  функция:     JNZ addr ( c — ): PC = addr, если c не равно 0; условие
               снимается со стека в любом случае; пустой стек — ловушка
               2.
  зависимости: ds_pop

МЕТОД op_call(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — абсолютный адрес байта в ОЗУ
  выход:       нет
  функция:     CALL addr ( — ): адрес возврата (текущий PC) кладётся на
               RS, PC = addr; переполнение RS — ловушка 5.
  зависимости: rs_push

МЕТОД op_ret(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — поле imm64 (игнорируется)
  выход:       нет
  функция:     RET ( — ): PC <- вершина RS; пустой RS — ловушка 4.
  зависимости: rs_pop

МЕТОД op_halt(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — код завершения (imm по модулю 256)
  выход:       нет — всегда поднимает UvmHalt
  функция:     HALT imm ( — ): нормальное завершение с кодом imm по
               модулю 256 (SPEC, раздел 5).
  зависимости: UvmHalt, to_byte

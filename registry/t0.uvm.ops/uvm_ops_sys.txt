КАРТОЧКИ ФАЙЛА tools/uvm_ops_sys.py

Ветвь: t0.uvm.ops
Слой: T0
Методов: 3
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Обработчик опкода SYS и мост к узлу-хосту: SYS 0 — чтение
          байта, SYS 1 — вывод байта (SPEC/L0-UVM.txt, раздел 6).

МЕТОД host_read_byte() -> int
  вход:        нет
  выход:       c: int — байт 0..255 или EOF_WORD при конце ввода
  функция:     Читает один байт из stdin узла-хоста (кирпич SYS 0).
  использует:  sys.stdin — стандартный ввод хоста

МЕТОД host_write_byte(c) -> None
  вход:        c: int — значение; выводится младший байт
  выход:       нет
  функция:     Пишет один байт (c по модулю 256) в stdout узла-хоста
               (кирпич SYS 1).
  использует:  sys.stdout — стандартный вывод хоста

МЕТОД op_sys(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — номер системного вызова n
  выход:       нет
  функция:     SYS n (SPEC, раздел 6): n = 0 — прочитать байт ( — c ), c
               = 0..255 или EOF_WORD в конце ввода; n = 1 — вывести байт
               ( c — ); неизвестный n — ловушка 8.
  зависимости: ds_push, ds_pop, host_read_byte, host_write_byte, trap

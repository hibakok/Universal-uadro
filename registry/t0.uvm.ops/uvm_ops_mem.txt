КАРТОЧКИ ФАЙЛА tools/uvm_ops_mem.py

Ветвь: t0.uvm.ops
Слой: T0
Методов: 4
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Обработчики опкодов группы «память»: LOAD8, LOAD64, STORE8,
          STORE64 (SPEC/L0-UVM.txt, раздел 5).

МЕТОД op_load8(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — поле imm64 (игнорируется)
  выход:       нет
  функция:     LOAD8 ( addr — u8 ): читает байт ОЗУ и расширяет нулями
               до слова; адрес вне ОЗУ — ловушка 7.
  зависимости: ds_pop, ds_push, load_byte

МЕТОД op_load64(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — поле imm64 (игнорируется)
  выход:       нет
  функция:     LOAD64 ( addr — w64 ): читает 8 байтов little-endian без
               требования выравнивания; адрес вне ОЗУ — ловушка 7.
  зависимости: ds_pop, ds_push, load_word

МЕТОД op_store8(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — поле imm64 (игнорируется)
  выход:       нет
  функция:     STORE8 ( val addr — ): пишет младший байт val; addr —
               вершина стека, val — под ним; адрес вне ОЗУ — ловушка 7.
  зависимости: ds_pop2, store_byte

МЕТОД op_store64(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — поле imm64 (игнорируется)
  выход:       нет
  функция:     STORE64 ( val addr — ): раскладывает слово val в 8 байтов
               little-endian; addr — вершина стека, val — под ним; адрес
               вне ОЗУ — ловушка 7.
  зависимости: ds_pop2, store_word

КАРТОЧКИ ФАЙЛА tools/uvm_ops_stack.py

Ветвь: t0.uvm.ops
Слой: T0
Методов: 8
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Обработчики опкодов группы «стек»: NOP, PUSH, DROP, DUP, SWAP,
          OVER, ROT, PICK (SPEC/L0-UVM.txt, раздел 5).

МЕТОД op_nop(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — поле imm64 (игнорируется)
  выход:       нет
  функция:     NOP ( — ): ничего не делает (SPEC, таблица опкодов).

МЕТОД op_push(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — слово imm64
  выход:       нет
  функция:     PUSH imm ( — imm ): кладёт константу на стек данных.
  зависимости: ds_push

МЕТОД op_drop(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — поле imm64 (игнорируется)
  выход:       нет
  функция:     DROP ( a — ): снимает вершину стека данных; пустой стек —
               ловушка 2.
  зависимости: ds_pop

МЕТОД op_dup(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — поле imm64 (игнорируется)
  выход:       нет
  функция:     DUP ( a — a a ): дублирует вершину; собран из PICK 0
               (SPEC, замечание о минимальности).
  зависимости: op_pick

МЕТОД op_swap(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — поле imm64 (игнорируется)
  выход:       нет
  функция:     SWAP ( a b — b a ): меняет местами два верхних элемента.
  зависимости: ds_pop, ds_push

МЕТОД op_over(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — поле imm64 (игнорируется)
  выход:       нет
  функция:     OVER ( a b — a b a ): копия второго сверху; собран из
               PICK 1.
  зависимости: op_pick

МЕТОД op_rot(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — поле imm64 (игнорируется)
  выход:       нет
  функция:     ROT ( a b c — b c a ): циклический сдвиг тройки верхних
               элементов.
  зависимости: ds_pop, ds_push

МЕТОД op_pick(m, imm) -> None
  вход:        m: Machine — состояние машины
  вход:        imm: int — глубина элемента (0 — вершина)
  выход:       нет
  функция:     PICK imm ( xN..x0 — xN..x0 xN ): копия элемента глубины
               imm (0 = DUP, 1 = OVER); глубина вне стека — ловушка 2.
  зависимости: ds_push, ds_pick

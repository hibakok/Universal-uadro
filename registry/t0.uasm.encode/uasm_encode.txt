КАРТОЧКИ ФАЙЛА tools/uasm_encode.py

Ветвь: t0.uasm.encode
Слой: T0
Методов: 9
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Кодирование записей uAsm в байты: слово little-endian с
          оборачиванием отрицательных, байт DB, разрешение операнда
          (литерал или имя), инструкции и директивы данных, размер
          записи для адресов прохода 1 (SPEC/L2-UASM.txt, разделы 4-7).

МЕТОД to_word(value) -> int
  вход:        value: int — значение литерала или имени (любое целое)
  выход:       word: int — слово 0..2^64-1
  функция:     Приводит значение к слову UVM: отрицательные значения
               оборачиваются по модулю 2^64 (SPEC/L0-UVM.txt, раздел 1;
               SPEC/L2-UASM.txt, раздел 4).

МЕТОД word_le(value) -> bytes
  вход:        value: int — значение (литерал, имя или слово)
  выход:       data: bytes — восемь байтов little-endian
  функция:     Кодирует слово: поле imm64 инструкции и аргумент DW —
               восемь байтов little-endian (SPEC/L2-UASM.txt, разделы
               5-6); отрицательное значение сначала оборачивается по
               модулю 2^64.
  зависимости: to_word

МЕТОД byte_of(value) -> int
  вход:        value: int — значение аргумента директивы DB
  выход:       byte: int — байт 0..255 либо None, если значение вне
               диапазона
  функция:     Проверяет аргумент DB на диапазон 0..255
               (SPEC/L2-UASM.txt, раздел 6); None — сигнал ошибки «байт
               вне диапазона».

МЕТОД resolve_value(text, symbols) -> tuple
  вход:        text: str — операнд инструкции или аргумент DB/DW
  вход:        symbols: dict — таблица символов (ветвь t0.uasm.symbols)
  выход:       pair: tuple — (значение, None) либо (None, текст ошибки):
  выход:       «литерал вне диапазона», «неизвестное имя X», «плохой
               литерал X»
  функция:     Разрешает операнд в значение (SPEC/L2-UASM.txt, разделы
               5-6): числовой литерал раздела 4 в диапазоне
               -2^63..2^64-1 либо имя из таблицы символов. Значение
               имени берётся как есть, без оборачивания: оборачивание
               отрицательных — при кодировании, кирпичами to_word и
               word_le.
  зависимости: parse_number, in_literal_range, is_name, symbol_get,
               bad_literal

МЕТОД encode_instr(mnemonic, operand, symbols) -> tuple
  вход:        mnemonic: str — мнемоника опкода
  вход:        operand: str — операнд-текст либо None (операнда нет)
  вход:        symbols: dict — таблица символов
  выход:       pair: tuple — (байты, None) либо (None, текст ошибки):
  выход:       «неизвестная мнемоника X», «нет операнда у X», «лишний
               операнд
  выход:       у X» и ошибки кирпича resolve_value
  функция:     Кодирует инструкцию (SPEC/L2-UASM.txt, раздел 5): байт
               опкода; у опкода с полем imm64 (PUSH, PICK, JMP, JZ, JNZ,
               CALL, HALT, SYS) — ещё восемь байтов little-endian со
               значением операнда. Кирпич полон: проверяет и вход,
               который разбор строки отверг бы.
  зависимости: entry_by_mnemonic, resolve_value, word_le

МЕТОД encode_db(args, symbols) -> tuple
  вход:        args: tuple — аргументы-тексты директивы DB
  вход:        symbols: dict — таблица символов
  выход:       pair: tuple — (байты, None) либо (None, текст ошибки):
  выход:       «пустая директива DB», «байт вне диапазона» и ошибки
               кирпича
  выход:       resolve_value
  функция:     Кодирует DB (SPEC/L2-UASM.txt, раздел 6): один байт на
               аргумент; значение аргумента разрешает resolve_value,
               байт даёт byte_of.
  зависимости: resolve_value, byte_of

МЕТОД encode_dw(args, symbols) -> tuple
  вход:        args: tuple — аргументы-тексты директивы DW
  вход:        symbols: dict — таблица символов
  выход:       pair: tuple — (байты, None) либо (None, текст ошибки):
  выход:       «пустая директива DW» и ошибки кирпича resolve_value
  функция:     Кодирует DW (SPEC/L2-UASM.txt, раздел 6): восемь байтов
               little-endian на аргумент; значение аргумента разрешает
               resolve_value, слово кодирует word_le.
  зависимости: resolve_value, word_le

МЕТОД record_size(record) -> int
  вход:        record: tuple — запись ветви t0.uasm.line: метка,
               константа,
  вход:        инструкция или директива данных
  выход:       size: int — размер записи в байтах
  функция:     Даёт размер записи для адресов прохода 1
               (SPEC/L2-UASM.txt, раздел 7): инструкция с полем imm64 —
               9 байтов, без — 1; DB — по байту на аргумент; DW — по 8
               байтов; DS и DZ — длина готовых байтов записи (нуль-байт
               DZ уже включён); метка, константа и неизвестная запись
               байтов не дают — 0.
  зависимости: entry_by_mnemonic

МЕТОД encode_record(record, symbols) -> tuple
  вход:        record: tuple — запись ветви t0.uasm.line
  вход:        symbols: dict — таблица символов
  выход:       pair: tuple — (байты, None) либо (None, текст ошибки):
               ошибки
  выход:       кирпичей кодирования, текст записи-ошибки либо «плохая
               запись»
  функция:     Кодирует запись целиком — вход прохода 2 сборки:
               инструкция — encode_instr; DB и DW — encode_db/encode_dw;
               DS и DZ — готовые байты записи; метка и константа байтов
               не дают; запись-ошибка возвращает свой текст; записи вне
               контракта — «плохая запись».
  зависимости: encode_instr, encode_db, encode_dw

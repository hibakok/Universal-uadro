МЕТОД to_word(x) -> int
  вход:        x: int — целое, возможно вне диапазона 64-битных слов
  выход:       w: int — значение по модулю 2^64
  функция:     Оборачивает целое в 64-битное слово: переполнения
               оборачиваются (SPEC, раздел 1).

МЕТОД to_byte(x) -> int
  вход:        x: int — целое, возможно вне 0..255
  выход:       b: int — младший байт 0..255
  функция:     Оставляет младшие 8 бит значения.

МЕТОД to_signed(w) -> int
  вход:        w: int — 64-битное слово без знака (возможно, вне
               диапазона)
  выход:       s: int — то же значение как знаковое -2^63..2^63-1
  функция:     Читает слово в дополнительном коде до двух; кирпич
               инструкции SAR и будущих знаковых операций слоя uBrick.

МЕТОД UvmTrap(code)
  вход:        code: int — код завершения-ловушки 1..8 (SPEC, раздел 3)
  выход:       exception — ловушка с полем code
  функция:     Ловушка немедленно завершает исполнение с указанным
               кодом; поднимается как исключение, ловит его цикл
               t0.uvm.run.

МЕТОД trap(code) -> None
  вход:        code: int — код ловушки
  выход:       нет — всегда поднимает UvmTrap
  функция:     Поднимает ловушку с кодом; исполнение немедленно
               завершается.
  зависимости: UvmTrap

МЕТОД UvmHalt(code)
  вход:        code: int — код завершения 0..255 (imm инструкции HALT по
  вход:        модулю 256)
  выход:       exception — нормальная остановка с полем code
  функция:     Нормальное завершение по HALT imm (SPEC, раздел 5): в
               отличие от ловушек UvmTrap ошибкой не является;
               поднимается обработчиком HALT ветви t0.uvm.ops, ловит
               цикл ветви t0.uvm.run.

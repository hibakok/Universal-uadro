_Тесты ядра UVM: слова, ловушки, ОЗУ, стеки DS/RS и загрузка образа._

### small(ram_size) -> Machine

- **вход:** ram_size: int — размер ОЗУ в байтах (по умолчанию 64)
- **выход:** m: Machine — машина с малым ОЗУ и малыми стеками
- **функция:** Компактная машина для быстрых тестов границ и переполнений.
- **зависимости:** uc.Machine

### trap_code(action) -> int

- **вход:** action: callable — действие, обязанное поднять ловушку
- **выход:** code: int — код поднятой ловушки
- **функция:** Исполняет действие и возвращает код ловушки; без ловушки — ошибка
- **функция:** теста.
- **зависимости:** uc.UvmTrap

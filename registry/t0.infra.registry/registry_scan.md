# Карточки файла tools/registry_scan.py

Ветвь t0.infra.registry, слой T0, методов: 20. Генерируется `tools/registry_scan.py`; вручную не редактировать.

_Генератор реестра методов: индекс registry/METHODS.md и карточки по исходным файлам registry/<ветвь>/<файл>.md. Режим --check сверяет реестр без записи._

### _strip_tag(line) -> tuple

- **вход:** line: str — строка исходного файла
- **выход:** pair: tuple — (ключ, значение) для строки "# @ключ значение", иначе (None, "")
- **функция:** Распознаёт строки-аннотации "# @ключ значение".

### parse_file_header(lines) -> dict

- **вход:** lines: list[str] — строки файла
- **выход:** header: dict — поля file, layer, branch, desc (список строк)
- **функция:** Читает шапку файла: непрерывный блок "# @..." в начале файла.

### parse_method_cards(lines) -> list

- **вход:** lines: list[str] — строки файла
- **выход:** cards: list[dict] — карточки с полями name, in, out, does, uses, depends
- **функция:** Собирает карточки: строка "@method" открывает карточку, последующие
- **функция:** строки "@in/@out/@does/@uses/@depends" наполняют её, любая другая
- **функция:** строка закрывает.

### collect_sources() -> list

- **вход:** нет
- **выход:** paths: list[Path] — отсортированные *.py из каталогов исходников
- **функция:** Обходит существующие каталоги SOURCE_DIRS и собирает .py-файлы.

### read_entries() -> list

- **вход:** нет
- **выход:** entries: list[dict] — элементы: path, header, cards
- **функция:** Читает все исходники и разбирает шапки и карточки.
- **зависимости:** collect_sources, parse_file_header, parse_method_cards

### branch_of(entry) -> str

- **вход:** entry: dict — элемент реестра (path, header, cards)
- **выход:** branch: str — имя ветви или no-branch, если в шапке нет ветви
- **функция:** Достаёт имя ветви из шапки файла.

### rel_path(entry) -> str

- **вход:** entry: dict — элемент реестра (path, header, cards)
- **выход:** rel: str — путь файла относительно корня репозитория
- **функция:** Преобразует путь в POSIX-вид для реестра.

### card_name_for(entry, used) -> str

- **вход:** entry: dict — элемент реестра (path, header, cards)
- **вход:** used: set[str] — уже занятые имена карточек этой ветви
- **выход:** name: str — имя файла карточек, уникальное внутри ветви
- **функция:** Строит имя карточек из имени исходника; при совпадении имён
- **функция:** внутри ветви добавляет числовой суффикс.

### plan_registry(entries) -> list

- **вход:** entries: list[dict] — элементы реестра
- **выход:** plan: list[dict] — элементы: branch, entry, card (имя файла карточек)
- **функция:** Назначает каждому исходнику его ветвь и имя файла карточек.
- **зависимости:** branch_of, card_name_for

### group_plan_by_branch(plan) -> dict

- **вход:** plan: list[dict] — план реестра
- **выход:** groups: dict — ветвь -> элементы плана в порядке обхода
- **функция:** Группирует элементы плана по ветвям.

### sort_plan_branches(groups) -> list

- **вход:** groups: dict — ветвь -> элементы плана
- **выход:** names: list[str] — имена ветвей в стабильном порядке (слой, имя)
- **функция:** Даёт стабильный порядок ветвей в индексе реестра.

### render_cards(entry) -> list

- **вход:** entry: dict — элемент реестра (path, header, cards)
- **выход:** lines: list[str] — markdown-строки: карточки методов файла
- **функция:** Рендерит карточки методов; файл без методов даёт пометку.

### render_card_file(item) -> str

- **вход:** item: dict — элемент плана реестра (branch, entry, card)
- **выход:** text: str — текст файла registry/<ветвь>/<файл>.md
- **функция:** Собирает карточки одного исходного файла: шапка с ветвью, слоем
- **функция:** и описанием, затем карточки методов.
- **зависимости:** rel_path, render_cards

### render_index(plan) -> str

- **вход:** plan: list[dict] — план реестра: branch, entry, card на исходник
- **выход:** text: str — текст индекса registry/METHODS.md
- **функция:** Формирует компактный индекс: ветви, их файлы со ссылками на карточки
- **функция:** и числом методов, плюс итог по репозиторию.
- **зависимости:** group_plan_by_branch, sort_plan_branches, rel_path

### render_all(entries) -> dict

- **вход:** entries: list[dict] — элементы реестра
- **выход:** files: dict — имя файла -> текст (индекс + карточки по файлам)
- **функция:** Рендерит весь реестр целиком.
- **зависимости:** plan_registry, render_index, render_card_file

### scan_repository() -> dict

- **вход:** нет
- **выход:** files: dict — имя файла -> текст реестра для текущих исходников
- **функция:** Обходит исходники и рендерит все файлы реестра.
- **зависимости:** read_entries, render_all

### check_registry(files) -> list

- **вход:** files: dict — имя файла -> ожидаемый текст
- **выход:** problems: list[str] — расхождения (пустой список = реестр актуален)
- **функция:** Сверяет ожидаемый реестр с файлами на диске, включая лишние файлы
- **функция:** во всех подкаталогах registry/.

### remove_extra_files(files) -> None

- **вход:** files: dict — имя файла -> текст; набор файлов, который должен существовать
- **выход:** нет
- **функция:** Удаляет в registry/ файлы вне ожидаемого набора и опустевшие
- **функция:** подкаталоги ветвей.

### write_registry(files) -> None

- **вход:** files: dict — имя файла -> текст
- **выход:** нет; файлы registry/ перезаписываются, лишние удаляются
- **функция:** Записывает реестр на диск, создавая подкаталоги ветвей.
- **зависимости:** remove_extra_files

### main(argv) -> int

- **вход:** argv: list[str] — аргументы командной строки
- **выход:** code: int — 0 — успех; 1 — реестр устарел (только для --check)
- **функция:** Без --check записывает реестр; с --check сверяет без записи.
- **зависимости:** scan_repository, check_registry, write_registry

КАРТОЧКИ ФАЙЛА tools/registry_render.py

Ветвь: t0.infra.registry
Слой: T0
Методов: 11
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Рендер реестра методов простым текстом: компактный индекс
          registry/METHODS.txt, индексы ветвей
          registry/<ветвь>/INDEX.txt и карточки по исходным файлам
          (сканирование, план и запись — tools/registry_scan.py).

МЕТОД wrap_words(text, width) -> list
  вход:        text: str — текст без переводов строк
  вход:        width: int — максимальная ширина строки
  выход:       lines: list[str] — строки не шире width
  функция:     Переносит текст по словам; слово длиннее width занимает
               строку целиком; пустой текст даёт пустой список.

МЕТОД merge_items(key, items) -> list
  вход:        key: str — ключ поля (in, out, does, uses, depends)
  вход:        items: list[str] — значения поля, как в исходнике
  выход:       merged: list[str] — абзацы поля после склейки
  функция:     Склеивает продолжения: @does — в один текст через пробел;
               @uses и @depends — в один список через запятую; @in и
               @out остаются отдельными строками.

МЕТОД render_field(title, items, indent) -> list
  вход:        title: str — название поля («вход», «функция», ...)
  вход:        items: list[str] — абзацы значения поля
  вход:        indent: str — отступ поля (по умолчанию два пробела)
  выход:       lines: list[str] — строки поля с переносами по словам
  функция:     Рендерит поле карточки: первая строка «<indent>метка:
               текст», продолжения выровнены под началом текста.
  зависимости: wrap_words

МЕТОД render_card(card) -> list
  вход:        card: dict — карточка метода (name, in, out, does, uses,
               depends)
  выход:       lines: list[str] — строки одной карточки в простом тексте
  функция:     Рендерит карточку: заголовок «МЕТОД ...» и поля с
               отступом.
  зависимости: merge_items, render_field

МЕТОД render_cards(entry) -> list
  вход:        entry: dict — элемент реестра (path, header, cards)
  выход:       lines: list[str] — карточки методов файла
  функция:     Рендерит карточки методов; файл без методов даёт пометку.
  зависимости: render_card

МЕТОД render_card_file(item) -> str
  вход:        item: dict — элемент плана реестра (branch, entry, card,
               rel)
  выход:       text: str — текст файла registry/<ветвь>/<файл>.txt
  функция:     Собирает карточки одного исходного файла: шапка с ветвью,
               слоем и описанием, затем карточки методов.
  зависимости: render_cards, wrap_words

МЕТОД group_plan_by_branch(plan) -> dict
  вход:        plan: list[dict] — план реестра
  выход:       groups: dict — ветвь -> элементы плана в порядке обхода
  функция:     Группирует элементы плана по ветвям.

МЕТОД sort_plan_branches(groups) -> list
  вход:        groups: dict — ветвь -> элементы плана
  выход:       names: list[str] — имена ветвей в стабильном порядке
               (слой, имя)
  функция:     Даёт стабильный порядок ветвей в индексах реестра.

МЕТОД render_branch_index(branch, items) -> str
  вход:        branch: str — имя ветви
  вход:        items: list[dict] — элементы плана ветви (branch, entry,
               card, rel)
  выход:       text: str — текст индекса ветви
               registry/<ветвь>/INDEX.txt
  функция:     Перечисляет исходники ветви: путь, число методов, путь
               карточек и описание из шапки файла; растёт только с
               числом файлов ветви, поэтому индекс верхнего уровня не
               перечисляет файлы (лимит строк CHARTER.txt, п. 3).
  зависимости: wrap_words

МЕТОД render_index(groups) -> str
  вход:        groups: dict — ветвь -> элементы плана
               (group_plan_by_branch)
  выход:       text: str — текст индекса registry/METHODS.txt
  функция:     Формирует компактный индекс верхнего уровня: ветви с
               числом файлов и методов и путём индекса ветви; файлы и
               описания перечисляет индекс ветви, поэтому индекс не
               растёт с числом файлов репозитория (лимит строк
               CHARTER.txt, п. 3).
  зависимости: sort_plan_branches

МЕТОД render_all(plan) -> dict
  вход:        plan: list[dict] — план реестра: branch, entry, card, rel
  выход:       files: dict — имя файла -> текст: индекс, индексы ветвей
  выход:       и карточки по исходным файлам
  функция:     Рендерит весь реестр целиком по плану.
  зависимости: group_plan_by_branch, sort_plan_branches, render_index,,
               render_branch_index, render_card_file

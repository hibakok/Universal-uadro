КАРТОЧКИ ФАЙЛА tools/ubrick_source.py

Ветвь: t0.ubrick.source
Слой: T0
Методов: 12
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Загрузчик исходников uBrick: оператор use — многофайловые
          исходники склеиваются в один текст со сквозной нумерацией
          строк (SPEC/L3-UBRICK.txt, v0.3, раздел 3); ошибки загрузчика
          предшествуют ошибкам разбора.

МЕТОД read_file_text(path) -> str
  вход:        path: str — путь к файлу исходника
  выход:       text: str — текст файла UTF-8 либо None при ошибке чтения
  функция:     Читает файл целиком; отсутствие файла, каталог и плохая
               кодировка дают None (сообщение печатает вызывающий).

МЕТОД new_loader() -> dict
  вход:        нет
  выход:       state: dict — lines (строки объединённого текста), stack
  выход:       (пути открытых включений), in_def (определение открыто),
  выход:       error (текст ошибки или None)
  функция:     Создаёт начальное состояние загрузчика.

МЕТОД loader_fail(loader, line_no, text) -> None
  вход:        loader: dict — состояние загрузчика; метод пишет error
  вход:        line_no: int — сквозной номер строки use
  вход:        text: str — текст ошибки без префикса
  выход:       нет
  функция:     Запоминает первую ошибку с номером строки (как fail
               разбора); повторные вызовы сообщение не меняют (SPEC,
               раздел 8).
  зависимости: wrap_error

МЕТОД use_target(tokens) -> tuple
  вход:        tokens: list — слова строки use (первое — само use)
  выход:       pair: tuple — (имя файла, None) либо (None, текст
               ошибки):
  выход:       «use без имени файла», «лишние слова после use»
  функция:     Даёт имя файла строки use (SPEC, раздел 3, v0.3): ровно
               два слова — use и имя; пробелы в имени невозможны
               (слова).

МЕТОД opens_definition(tokens, in_def) -> bool
  вход:        tokens: list — слова строки до «;»-хвоста
  вход:        in_def: bool — определение открыто
  выход:       flag: bool — True, если строка открывает определение
  функция:     Определение открывает «:» первым словом строки верхнего
               уровня (как top_line разбора); «:» внутри тела — ошибка
               разбора, состояние загрузчика не меняет.

МЕТОД closes_definition(tokens, tail, in_def) -> bool
  вход:        tokens: list — слова строки до «;»-хвоста
  вход:        tail: bool — строка обрезана «;» вне кавычек
  вход:        in_def: bool — определение открыто
  выход:       flag: bool — True, если строка закрывает определение
  функция:     Определение закрывает обрезавший строку «;» с непустой
               головой (как process_line разбора: строка-комментарий
               определение не закрывает); вне определения такой «;» —
               ошибка разбора, состояние не меняется.

МЕТОД use_path(base_dir, name) -> str
  вход:        base_dir: str — каталог включающего файла
  вход:        name: str — имя файла из строки use
  выход:       path: str — путь к включаемому файлу
  функция:     Строит путь use-файла относительно каталога включающего
               файла (SPEC, раздел 3, v0.3).

МЕТОД in_cycle(loader, path) -> bool
  вход:        loader: dict — состояние загрузчика
  вход:        path: str — абсолютный путь включаемого файла
  выход:       flag: bool — True, если файл уже в стеке включений
  функция:     Признаёт циклическое включение (SPEC, раздел 8, v0.3):
               файл из стека включает себя транзитивно.

МЕТОД source_line(loader, base_dir, raw) -> None
  вход:        loader: dict — состояние загрузчика
  вход:        base_dir: str — каталог файла, которому принадлежит
               строка
  вход:        raw: str — исходная строка текста
  выход:       нет; строка добавляется к объединённому тексту,
               use-строка
  выход:       заменяется строками включённого файла; ошибка — error
  функция:     Обрабатывает одну строку исходника (SPEC, раздел 3,
               v0.3): «;» вне кавычек делит строку на голову и хвост,
               слова — split_words; строка use вне определения —
               включение файла include_file либо ошибка use_target;
               строка use внутри определения — «use внутри определения»;
               прочие строки идут в объединённый текст, состояние
               определения ведут opens_definition и closes_definition.
  зависимости: find_outside_quotes, split_words, use_target,
               include_file,, opens_definition, closes_definition,
               loader_fail

МЕТОД file_lines(text) -> list
  вход:        text: str — текст включаемого файла
  выход:       lines: list — строки файла без артефакта концевого
               перевода
  функция:     Делит текст файла на строки (split_lines): концевой
               перевод строки файла — конец последней строки, не пустая
               строка после неё; пустой файл — ноль строк.
  зависимости: split_lines

МЕТОД include_file(loader, base_dir, name, line_no) -> None
  вход:        loader: dict — состояние загрузчика
  вход:        base_dir: str — каталог включающего файла
  вход:        name: str — имя файла из строки use
  вход:        line_no: int — сквозной номер строки use
  выход:       нет; строки включённого файла встают на место строки use;
  выход:       ошибка — error
  функция:     Включает файл (SPEC, раздел 3, v0.3): путь — use_path;
               цикл — «циклический use X»; нечитаемый файл — «не
               читается use-файл X»; строки файла (file_lines)
               обрабатывает source_line с базой — каталогом включённого
               файла (его use-пути относительны ему).
  зависимости: use_path, in_cycle, read_file_text, file_lines,
               source_line,, loader_fail

МЕТОД resolve_uses(base_path, text) -> tuple
  вход:        base_path: str — путь главного исходника (каталог — база
               его
  вход:        use-путей)
  вход:        text: str — текст главного исходника
  выход:       pair: tuple — (объединённый текст, None) либо (None,
               «uBrick:
  выход:       строка N: текст»)
  функция:     Склеивает многофайловый исходник (SPEC, раздел 3, v0.3):
               строки use заменяются строками включённых файлов,
               нумерация строк объединённого текста сквозная; текст без
               use-строк возвращается неизменным (round-trip split_lines
               точен, концевые CR строк снимаются как в разборе).
               Главный файл кладётся в стек включений: возврат к нему —
               цикл.
  зависимости: new_loader, split_lines, source_line

КАРТОЧКИ ФАЙЛА tools/uasm_cli.py

Ветвь: t0.uasm.cli
Слой: T0
Методов: 11
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Командные режимы uAsm: asm — сборка текста в образ, dis —
          дизассемблирование образа в файл или stdout (SPEC/L2-UASM.txt,
          раздел 9).

МЕТОД usage_text() -> str
  вход:        нет
  выход:       text: str — строка подсказки команды
  функция:     Даёт текст обеих форм запуска, который main печатает в
               stderr при ошибке аргументов (SPEC/L2-UASM.txt, раздел
               9).

МЕТОД parse_asm_args(rest) -> tuple
  вход:        rest: list — аргументы после слова asm
  выход:       parsed: tuple — ("asm", источник, образ) либо None
  функция:     Режим asm: ровно два пути — исходник и образ.

МЕТОД parse_dis_args(rest) -> tuple
  вход:        rest: list — аргументы после слова dis
  выход:       parsed: tuple — ("dis", образ, текст либо None) либо None
  функция:     Режим dis: путь образа и, возможно, путь текста; без
               текста результат печатается в stdout.

МЕТОД parse_args(argv) -> tuple
  вход:        argv: list — аргументы командной строки без имени
               программы
  выход:       parsed: tuple — ("asm", источник, образ) либо ("dis",
               образ,
  выход:       текст либо None) либо None
  функция:     Разбирает аргументы: первое слово — режим asm или dis,
               дальше аргументы режима; пустые аргументы и неизвестный
               режим — None.
  зависимости: parse_asm_args, parse_dis_args

МЕТОД read_text(path) -> str
  вход:        path: str — путь к файлу исходника uAsm
  выход:       text: str — текст файла либо None
  функция:     Читает исходник целиком в кодировке UTF-8; отсутствие
               файла, каталог и плохая кодировка дают None (сообщение
               печатает вызывающий режим).

МЕТОД read_image(path) -> bytes
  вход:        path: str — путь к файлу образа
  выход:       image: bytes — байты образа либо None
  функция:     Читает файл образа целиком; ошибки доступа дают None.

МЕТОД write_bytes(path, data) -> str
  вход:        path: str — путь к файлу образа
  вход:        data: bytes — байты образа
  выход:       error: str — текст ошибки записи либо None при успехе
  функция:     Пишет байты в файл; ошибки доступа дают текст ошибки для
               stderr.

МЕТОД write_text(path, text) -> str
  вход:        path: str — путь к файлу текста
  вход:        text: str — текст uAsm
  выход:       error: str — текст ошибки записи либо None при успехе
  функция:     Пишет текст в файл в кодировке UTF-8; ошибки доступа дают
               текст ошибки для stderr.

МЕТОД run_asm(parsed) -> int
  вход:        parsed: tuple — ("asm", источник, образ) из parse_args
  выход:       code: int — 0 — образ собран и записан; 2 — ошибка
  функция:     Режим asm: читает исходник (read_text), собирает
               (assemble), пишет образ (write_bytes); ошибка сборки
               печатается в stderr как есть («uAsm: строка N: текст»),
               ошибки файлов — своим сообщением; код ошибки — 2 (SPEC,
               раздел 9).
  использует:  sys.stderr — стандартный вывод ошибок хоста
  зависимости: read_text, assemble, write_bytes

МЕТОД run_dis(parsed) -> int
  вход:        parsed: tuple — ("dis", образ, текст либо None) из
               parse_args
  выход:       code: int — 0 — текст получен; 2 — ошибка чтения или
               записи
  функция:     Режим dis: читает образ (read_image), дизассемблирует
               (disasm), пишет текст в файл (write_text) либо, без
               файла, в stdout; ошибки файлов — код 2 и сообщение в
               stderr (SPEC, раздел 9).
  использует:  sys.stderr, sys.stdout — стандартные потоки хоста
  зависимости: read_image, disasm, write_text

МЕТОД main(argv) -> int
  вход:        argv: list — аргументы командной строки без имени
               программы
  выход:       code: int — 0 — успех; 2 — ошибка аргументов или режима
  функция:     Полный запуск команды: parse_args, затем режим asm
               (run_asm) или dis (run_dis); ошибка аргументов печатает
               подсказку использования в stderr.
  использует:  sys.stderr — стандартный вывод ошибок хоста
  зависимости: usage_text, parse_args, run_asm, run_dis

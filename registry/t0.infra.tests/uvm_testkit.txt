КАРТОЧКИ ФАЙЛА tests/uvm_testkit.py

Ветвь: t0.infra.tests
Слой: T0
Методов: 4
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Общий тест-набор UVM: компактные машины, снимки стека, чтение
          кодов ловушек и остановки для тестов ветвей t0.uvm.*.

МЕТОД small(ram_size, ds_size, rs_size) -> Machine
  вход:        ram_size: int — размер ОЗУ в байтах (по умолчанию 64)
  вход:        ds_size: int — ёмкость стека данных в словах (по
               умолчанию 8)
  вход:        rs_size: int — ёмкость стека возвратов в словах (по
               умолчанию 4)
  выход:       m: Machine — машина с малым ОЗУ и малыми стеками
  функция:     Компактная машина для быстрых тестов границ и
               переполнений; размеры переопределяются точечно.
  зависимости: uc.Machine

МЕТОД stack_of(m) -> list
  вход:        m: Machine — состояние машины
  выход:       items: list — снимок стека данных (нижний элемент первым)
  функция:     Копия содержимого DS для сравнения в тестах.

МЕТОД trap_code(action) -> int
  вход:        action: callable — действие, обязанное поднять ловушку
  выход:       code: int — код поднятой ловушки
  функция:     Исполняет действие и возвращает код ловушки; без ловушки
               — ошибка теста.
  зависимости: uc.UvmTrap

МЕТОД halt_code(action) -> int
  вход:        action: callable — действие, обязанное поднять UvmHalt
  выход:       code: int — код нормальной остановки
  функция:     Исполняет действие и возвращает код остановки HALT; без
               остановки — ошибка теста.
  зависимости: uc.UvmHalt

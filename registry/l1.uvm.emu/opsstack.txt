КАРТОЧКИ ФАЙЛА src/l1/opsstack.ubrk

Ветвь: l1.uvm.emu
Слой: L1
Методов: 8
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Эмулятор UVM — обработчики группы «стек» 0x00-0x07 (SPEC/
          L0-UVM.txt, раздел 5; SPEC/L4-SELFHOST.txt, раздел 5Б):
          подшаги 2 и 3 — все восемь кодов группы: NOP, PUSH, DROP, DUP,
          SWAP, OVER, ROT, PICK; кирпичи стеков гостя — mem.ubrk
          (gpush/gpop/gpick), имена обработчиков — мнемоники строчными.

МЕТОД nop ( -- )
  вход:        нет (клетка gpc уже переведена декодером за инструкцию)
  выход:       нет
  функция:     Обработчик NOP 0x00 (SPEC/L0-UVM.txt, раздел 5: эффект (
               — ), ничего не делать): тело пусто — следующий адрес уже
               в gpc (decode, dec.ubrk); кирпич dstack (tab.ubrk).
  зависимости: нет

МЕТОД push ( -- )
  вход:        нет (клетка gv — imm инструкции; gpc уже переведён
               декодером)
  выход:       нет; imm лежит в DS гостя
  функция:     Обработчик PUSH imm 0x01 (эффект ( — imm )): кладёт
               значение поля imm64 на стек данных гостя (как op_push
               эталона, t0.uvm.ops) — gpush (переполнение DS — ловушка
               3); кирпич dstack (tab.ubrk).
  зависимости: gv, gpush

МЕТОД drop ( -- )
  вход:        нет (gpc уже переведён декодером за инструкцию)
  выход:       нет; вершина DS гостя снята
  функция:     Обработчик DROP 0x02 (эффект ( a — )): снимает вершину
               стека данных гостя (как op_drop эталона) — gpop (пустой
               стек — ловушка 2), значение отбрасывается; кирпич dstack
               (tab.ubrk).
  зависимости: gpop, DROP

МЕТОД dup ( -- )
  вход:        нет (gpc уже переведён декодером за инструкцию)
  выход:       нет; вершина DS гостя продублирована
  функция:     Обработчик DUP 0x03 (эффект ( a — a a )): дублирует
               вершину стека данных гостя (как op_dup эталона — PICK 0):
               копия глубины 0 — gpush (пустой стек — ловушка 2 у gpick,
               переполнение — ловушка 3); кирпич dstack (tab.ubrk).
  зависимости: gpick, gpush

МЕТОД swap ( -- )
  вход:        нет (gpc уже переведён декодером за инструкцию)
  выход:       нет; два верхних слова DS гостя поменяли местами
  функция:     Обработчик SWAP 0x04 (эффект ( a b -- b a )): gpop
               снимает оба слова на стек узла, SWAP меняет их порядок,
               gpush кладёт обратно (как op_swap эталона); меньше двух
               слов — ловушка 2, переполнение — ловушка 3; кирпич dstack
               (tab.ubrk).
  зависимости: gpop, SWAP, gpush

МЕТОД over ( -- )
  вход:        нет (gpc уже переведён декодером за инструкцию)
  выход:       нет; копия второго сверху слова лежит в DS гостя
  функция:     Обработчик OVER 0x05 (эффект ( a b -- a b a )): копия
               слова глубины 1 (как op_over эталона — PICK 1) — gpush;
               меньше двух слов — ловушка 2 у gpick, переполнение —
               ловушка 3; кирпич dstack (tab.ubrk).
  зависимости: gpick, gpush

МЕТОД rot ( -- )
  вход:        нет (gpc уже переведён декодером за инструкцию)
  выход:       нет; тройка верхних слов DS гостя сдвинута циклически
  функция:     Обработчик ROT 0x06 (эффект ( a b c -- b c a )): gpop
               снимает тройку на стек узла (порядок обращён), два ROT
               ставят её в порядок-push (b, c, a), gpush кладёт обратно
               (как op_rot эталона); меньше трёх слов — ловушка 2,
               переполнение — ловушка 3; кирпич dstack (tab.ubrk).
  зависимости: gpop, ROT, gpush

МЕТОД pick ( -- )
  вход:        нет (клетка gv — глубина imm; gpc уже переведён
               декодером)
  выход:       нет; копия слова глубины imm лежит в DS гостя
  функция:     Обработчик PICK imm 0x07 (эффект ( xN..x0 -- xN..x0 xN
               )): копия слова глубины imm (0 = DUP, 1 = OVER) — gpick
               (глубина вне стека — ловушка 2, сравнение беззнаковое) и
               gpush (как op_pick эталона); кирпич dstack (tab.ubrk).
  зависимости: gv, gpick, gpush

КАРТОЧКИ ФАЙЛА src/l1/opsmem.ubrk

Ветвь: l1.uvm.emu
Слой: L1
Методов: 4
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Эмулятор UVM — обработчики группы «память» 0x10-0x13 (SPEC/
          L0-UVM.txt, раздел 5; SPEC/L4-SELFHOST.txt, раздел 5Б): подшаг
          4 — LOAD8, LOAD64, STORE8, STORE64; кирпичи памяти гостя —
          mem.ubrk (gloadbyte, gloadword, gstorebyte, gstoreword), имена
          обработчиков — мнемоники строчными.

МЕТОД load8 ( -- )
  вход:        нет (gpc уже переведён декодером за инструкцию)
  выход:       нет; байт ОЗУ гостя (расширенный нулями) лежит в DS гостя
  функция:     Обработчик LOAD8 0x10 (эффект ( addr -- u8 )): gpop
               снимает адрес со стека гостя, gloadbyte читает байт ОЗУ
               гостя (адрес вне ОЗУ — ловушка 7), gpush кладёт результат
               (как op_load8 эталона, t0.uvm.ops); пустой стек — ловушка
               2; кирпич dmem (tab.ubrk).
  зависимости: gpop, gloadbyte, gpush

МЕТОД load64 ( -- )
  вход:        нет (gpc уже переведён декодером за инструкцию)
  выход:       нет; 64-битное слово ОЗУ гостя лежит в DS гостя
  функция:     Обработчик LOAD64 0x11 (эффект ( addr -- w64 )): gpop
               снимает адрес, gloadword читает восемь байтов
               little-endian без требования выравнивания (каждый байт
               проверен — ловушка 7), gpush кладёт слово (как op_load64
               эталона); пустой стек — ловушка 2; кирпич dmem
               (tab.ubrk).
  зависимости: gpop, gloadword, gpush

МЕТОД store8 ( -- )
  вход:        нет (gpc уже переведён декодером за инструкцию)
  выход:       нет; младший байт val записан в ОЗУ гостя по адресу addr
  функция:     Обработчик STORE8 0x12 (эффект ( val addr -- )): gpop
               снимает со стека гостя addr и val (на стеке узла — addr
               глубже, val вершина), gstorebyte пишет младший байт val
               (адрес вне ОЗУ — ловушка 7, как op_store8 и store_byte
               эталона); меньше двух слов — ловушка 2; кирпич dmem
               (tab.ubrk).
  зависимости: gpop, gstorebyte

МЕТОД store64 ( -- )
  вход:        нет (gpc уже переведён декодером за инструкцию)
  выход:       нет; восемь байтов val записаны в ОЗУ гостя little-endian
  функция:     Обработчик STORE64 0x13 (эффект ( val addr -- )): gpop
               снимает со стека гостя addr и val, gstoreword
               раскладывает val в восемь байтов LE (каждый байт проверен
               — ловушка 7, как op_store64 и store_word эталона); меньше
               двух слов — ловушка 2; кирпич dmem (tab.ubrk).
  зависимости: gpop, gstoreword

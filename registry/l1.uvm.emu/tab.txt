МЕТОД dispatch ( -- )
  вход:        нет (клетка gc — код инструкции; decode уже перевёл gpc)
  выход:       нет; CALL слова группы либо обработчика — дерево
               диапазонов
  функция:     Таблица обработчиков — дерево вложенных IF по шести
               диапазонам (SPEC/L4-SELFHOST.txt, раздел 5Б): 0x00-0x07 —
               dstack, 0x10-0x13 — dmem, 0x20-0x2C — darith, 0x30-0x35 —
               dcmp, 0x40-0x45 — djump, 0x50 — dsys; decode уже проверил
               принадлежность кода (ловушка 6 в декодере), поэтому
               последний диапазон достаётся без сравнения; кирпич цикла
               main (emu.ubrk).
  зависимости: gc, LEU, DUP, DROP, dstack, dmem, darith, dcmp, djump,
               dsys

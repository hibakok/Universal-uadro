Ветвь: l1.uvm.emu
Слой: L1
Методов: 7
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Эмулятор UVM — дерево диапазонов: таблица обработчиков (SPEC/
          L4-SELFHOST.txt, раздел 5Б, подшаг 2): dispatch — вложенные IF
          по шести диапазонам SPEC/L0-UVM.txt (раздел 5), внутри — слова
          групп, по коду — CALL обработчика (ops*.ubrk, по файлу на
          группу, как t0.uvm.ops); коды без обработчика — ловушка 6:
          заготовка подшагов 3-6 (стеки, память, арифметика и сравнения,
          переходы и SYS).

МЕТОД dstack ( -- )
  вход:        нет (клетка gc — код; gpc уже переведён декодером за
               инструкцию)
  выход:       нет; CALL обработчика группы «стек» — либо ловушка 6
  функция:     Группа «стек» 0x00-0x07 (SPEC/L0-UVM.txt, раздел 5): NOP
               (0x00) — обработчик nop (opsstack.ubrk); PUSH, DROP, DUP,
               SWAP, OVER, ROT, PICK — подшаг 3 (пока ловушка 6); кирпич
               dispatch.
  зависимости: gc, EQ, DUP, DROP, IF, EXIT, THEN, nop, STOP

МЕТОД dispatch ( -- )
  вход:        нет (клетка gc — код инструкции; decode уже перевёл gpc)
  выход:       нет; CALL слова группы либо обработчика — дерево
               диапазонов
  функция:     Таблица обработчиков — дерево вложенных IF по шести
               диапазонам (SPEC/L4-SELFHOST.txt, раздел 5Б): 0x00-0x07 —
               dstack, 0x10-0x13 — dmem, 0x20-0x2C — darith, 0x30-0x35 —
               dcmp, 0x40-0x45 — djump, 0x50 — dsys; decode уже проверил
               принадлежность кода (ловушка 6 в декодере), поэтому
               последний диапазон достаётся без сравнения; кирпич цикла
               main (emu.ubrk).
  зависимости: gc, LEU, DUP, DROP, dstack, dmem, darith, dcmp, djump,
               dsys

КАРТОЧКИ ФАЙЛА src/l1/opsjump.ubrk

Ветвь: l1.uvm.emu
Слой: L1
Методов: 6
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Эмулятор UVM — обработчики группы «переходы» 0x40-0x45 (SPEC/
          L0-UVM.txt, разделы 4-5; SPEC/L4-SELFHOST.txt, раздел 5Б):
          подшаги 2 и 6 — JMP, JZ, JNZ, CALL, RET, HALT. Переходы
          переписывают gpc сами (декодер уже перевёл его за инструкцию
          целиком — контракт обработчиков, как t0.uvm.exec), CALL кладёт
          адрес возврата на RS гостя (rpush — ловушка 5) прежде
          перехода, RET снимает его (rpop — ловушка 4); адрес перехода
          за пределы ОЗУ гостя ловит следующий decode — gloadbyte по gpc
          вне ОЗУ, ловушка 7 (как выборка эталона).

МЕТОД jmp ( -- )
  вход:        нет (клетка gv — абсолютный адрес перехода; gpc уже
               переведён
  вход:        декодером за инструкцию)
  выход:       нет; gpc = адрес перехода
  функция:     Обработчик JMP addr 0x40 (SPEC/L0-UVM.txt, раздел 5: PC =
               addr, адрес абсолютный): gv переписывает gpc (как op_jmp
               эталона, t0.uvm.ops); адрес за ОЗУ гостя ловит следующий
               decode — ловушка 7; кирпич djump (tab.ubrk).
  зависимости: gv, gpcaddr, LOAD64, STORE64

МЕТОД jz ( -- )
  вход:        нет (клетка gv — адрес перехода; gpc уже переведён
               декодером)
  выход:       нет; при нулевом условии gpc = адрес перехода
  функция:     Обработчик JZ addr 0x41 (эффект ( c -- )): gpop снимает
               условие со стека гостя (пустой — ловушка 2), not даёт
               флаг «c = 0» (словарь uBrick: 0 EQ), IF выполняет переход
               — gv в gpc (как op_jz эталона); условие снимается в любом
               случае; кирпич djump (tab.ubrk).
  зависимости: gpop, not, IF, THEN, gv, gpcaddr, LOAD64, STORE64

МЕТОД jnz ( -- )
  вход:        нет (клетка gv — адрес перехода; gpc уже переведён
               декодером)
  выход:       нет; при ненулевом условии gpc = адрес перехода
  функция:     Обработчик JNZ addr 0x42 (эффект ( c -- )): gpop снимает
               условие (пустой стек — ловушка 2), IF выполняет переход
               при c не 0 — gv в gpc (как op_jnz эталона); условие
               снимается в любом случае; кирпич djump (tab.ubrk).
  зависимости: gpop, IF, THEN, gv, gpcaddr, LOAD64, STORE64

МЕТОД call ( -- )
  вход:        нет (клетка gv — адрес перехода; gpc уже переведён
               декодером
  вход:        за инструкцию целиком)
  выход:       нет; адрес возврата на RS гостя, gpc = адрес перехода
  функция:     Обработчик CALL addr 0x43 (SPEC/L0-UVM.txt, раздел 4):
               rpush кладёт адрес возврата — gpc после decode, байт за
               полем imm64 (переполнение RS — ловушка 5 прежде перехода,
               как rs_push эталона в op_call), затем gv переписывает
               gpc; кирпич djump (tab.ubrk).
  зависимости: gpcaddr, LOAD64, rpush, gv, STORE64

МЕТОД ret ( -- )
  вход:        нет (gpc уже переведён декодером за инструкцию)
  выход:       нет; gpc = адрес возврата, снятый с RS гостя
  функция:     Обработчик RET 0x44: rpop снимает адрес возврата (пустой
               RS — ловушка 4, как rs_pop эталона в op_ret) и
               переписывает gpc; кирпич djump (tab.ubrk).
  зависимости: rpop, gpcaddr, STORE64

МЕТОД halt ( -- )
  вход:        нет (клетка gv — imm инструкции; gpc уже переведён
               декодером)
  выход:       нет; не возвращается: программа завершается
  функция:     Обработчик HALT imm 0x45 (SPEC/L0-UVM.txt, разделы 3 и
               5): нормальное завершение с кодом imm по модулю 256 — код
               гостя передаётся SYS 2 узла словом STOP
               (SPEC/L4-SELFHOST.txt, раздел 5Б); кирпич djump
               (tab.ubrk).
  зависимости: gv, STOP

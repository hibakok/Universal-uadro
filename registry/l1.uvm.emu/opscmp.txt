Ветвь: l1.uvm.emu
Слой: L1
Методов: 6
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Эмулятор UVM — обработчики группы «сравнения» 0x30-0x35 (SPEC/
          L0-UVM.txt, раздел 5; SPEC/L4-SELFHOST.txt, раздел 5Б): подшаг
          5 — EQ, NEQ, LTU, GTU, LEU, GEU: gpop снимает пару слов гостя,
          сравнение узла даёт флаг 1/0, gpush кладёт флаг в DS гостя;
          сравнения беззнаковые (слова — целые без знака), EQ/NEQ
          коммутативны (без SWAP), порядок остальных — SWAP: после gpop
          gpop на стеке узла [b, a] (a — вершина), SWAP даёт порядок ( a
          b ); имена — мнемоники строчными.

МЕТОД eq ( -- )
  вход:        нет (gpc уже переведён декодером за инструкцию)
  выход:       нет; флаг 1/0 лежит в DS гостя
  функция:     Обработчик EQ 0x30 (эффект ( a b -- ф )): gpop снимает
               оба слова гостя (меньше двух — ловушка 2), EQ узла даёт 1
               при равенстве, иначе 0 (коммутативно — без SWAP), gpush
               кладёт флаг (как op_eq и push_flag эталона, t0.uvm.ops);
               кирпич dcmp (tab.ubrk).
  зависимости: gpop, EQ, gpush

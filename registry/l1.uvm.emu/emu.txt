КАРТОЧКИ ФАЙЛА src/l1/emu.ubrk

Ветвь: l1.uvm.emu
Слой: L1
Методов: 2
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Эмулятор UVM — собственное воплощение Этапа 4: вход — образ
          гостя в stdin (KEY), выход — вывод программы гостя (EMIT), код
          завершения — код гостя: imm HALT по модулю 256 либо код
          ловушки 1-8 (SPEC/L4-SELFHOST.txt, разделы 4 и 5Б). Подшаги
          1-6: раскладка и чтение образа гостя (mem.ubrk: ловушка 7 при
          входе длиннее 512 КиБ — код 7, вывод пуст), клетки машины
          гостя (greset), декодер (dec.ubrk: шесть диапазонов, поле
          imm64, ловушки 6/7), дерево диапазонов (tab.ubrk) и цикл
          «decode dispatch»: обработчики всех 38 опкодов v0.1 — группы
          «стек» (opsstack.ubrk), «память» (opsmem.ubrk), «арифметика»
          (opsarith.ubrk), «сравнения» (opscmp.ubrk), «переходы»
          (opsjump.ubrk: JMP/JZ/JNZ/CALL/RET — кирпичи rpush/rpop) и
          SYS-мост (opssys.ubrk: SYS 0/1/2, прочий номер — ловушка 8);
          остаются подшаги 7 (золотой набор и сквозной прогон —
          SPEC/L4-SELFHOST.txt, разделы 5Б и 6); use-включения —
          SPEC/L3-UBRICK.txt, раздел 3.

МЕТОД imgstep ( cur -- cur' done )
  вход:        cur: слово — адрес узла следующего байта образа гостя
  выход:       cur': слово — адрес узла следующего байта после шага
  выход:       done: слово — 0: байт прочитан и записан; 1: EOF
  функция:     Один шаг чтения образа гостя из stdin
               (SPEC/L4-SELFHOST.txt, раздел 5Б): keyok читает байт;
               байт при наличии места (imgroom) — imgput пишет его в ОЗУ
               гостя, шаг возвращает 0; вход длиннее 512 КиБ — ловушка 7
               гостя до начала исполнения: STOP с кодом 7 и пустым
               выводом, шаг не возвращается; EOF — 1, курсор не
               меняется; как readstep ассемблера (раздел 5А).
  зависимости: keyok, imgroom, imgput, STOP

МЕТОД main ( -- )
  вход:        нет (вход инструмента — байты stdin, KEY: образ гостя)
  выход:       нет (выход — байты SYS 1 гостя, EMIT; код завершения —
               код
  выход:       гостя: imm HALT по модулю 256 либо код ловушки 1-8)
  функция:     Эмулятор UVM (SPEC/L4-SELFHOST.txt, раздел 5Б): читает
               образ гостя целиком в его ОЗУ (imgstep с адреса grambase
               до EOF; вход длиннее 512 КиБ — ловушка 7, код 7, вывод
               пуст), снимает курсор чтения со стека, greset ставит PC =
               0 и пустые стеки (SPEC/L0-UVM.txt, раздел 2), затем цикл
               инструкций — шаг decode (dec.ubrk: код, поле imm64, gpc —
               за инструкцией) + dispatch (tab.ubrk: дерево диапазонов,
               CALL обработчика) до STOP обработчика — HALT imm, SYS 2
               либо ловушка гостя; подшаги 5-6 добавили арифметику и
               сравнения, переходы и SYS-мост — все группы опкодов
               исполняются; SYS 1 гостя — EMIT, SYS 0 — всегда EOF:
               stdin инструмента израсходован образом); цикл не
               завершается сам — только STOP (BEGIN AGAIN).
  зависимости: grambase, imgstep, DROP, greset, decode, dispatch,
               BEGIN,, UNTIL, AGAIN

КАРТОЧКИ ФАЙЛА src/l1/opssys.ubrk

Ветвь: l1.uvm.emu
Слой: L1
Методов: 1
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Эмулятор UVM — SYS-мост 0x50 (SPEC/L0-UVM.txt, раздел 6;
          SPEC/L4-SELFHOST.txt, раздел 5Б, подшаг 6): SYS 0 гостя — KEY
          узла на DS гостя (stdin инструмента израсходован образом —
          всегда признак конца ввода 0xFFFFFFFFFFFFFFFF, как SYS 0
          эталона с пустым stdin); SYS 1 — gpop и EMIT (байт вывода — по
          модулю 256); SYS 2 — gpop и STOP: нормальная остановка с кодом
          гостя; прочий номер — ловушка 8.

МЕТОД sys ( -- )
  вход:        нет (клетка gv — номер системного вызова n; gpc уже
               переведён
  вход:        декодером за инструкцию)
  выход:       нет; эффект SYS на машине гостя, либо не возвращается
               (SYS 2)
  функция:     Обработчик SYS n 0x50 — мост к узлу
               (SPEC/L4-SELFHOST.txt, раздел 5Б): n = 0 — KEY читает
               stdin узла и кладёт байт (или признак конца ввода
               0xFFFFFFFFFFFFFFFF) на DS гостя — образ уже израсходовал
               stdin, поэтому всегда признак конца, как host_read_byte
               эталона с пустым stdin; n = 1 — gpop снимает байт гостя
               (пустой стек — ловушка 2), EMIT выводит его младший байт;
               n = 2 — gpop снимает код со стека гостя (пустой — ловушка
               2), STOP завершает инструмент кодом гостя по модулю 256 —
               нормальная остановка, как HALT imm (op_sys эталона);
               прочий n — ловушка 8 (STOP с кодом 8); кирпич dsys
               (tab.ubrk).
  зависимости: gv, LOAD64, EQ, DUP, DROP, IF, EXIT, THEN, KEY, gpush,
               gpop,, EMIT, STOP

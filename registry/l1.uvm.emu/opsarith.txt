Ветвь: l1.uvm.emu
Слой: L1
Методов: 13
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Эмулятор UVM — обработчики группы «арифметика» 0x20-0x2C
          (SPEC/ L0-UVM.txt, раздел 5; SPEC/L4-SELFHOST.txt, раздел 5Б):
          подшаг 5 — ADD, SUB, MUL, UDIV, UMOD, NEG, SHL, SHR, SAR, AND,
          OR, XOR, INV. Бинарные снимают два слова стека гостя (gpop),
          вычисляют на стеке узла примитивами uBrick (та же семантика по
          модулю 2^64), кладут результат обратно (gpush); делитель 0 у
          UDIV/UMOD — ловушка 1 гостя; имена обработчиков — мнемоники
          строчными. Коммутативные операции идут без SWAP (порядок
          операндов не важен), некоммутативные — SWAP: после gpop gpop
          на стеке узла [b, a] (a — вершина), SWAP даёт порядок ( a b ).

МЕТОД add ( -- )
  вход:        нет (gpc уже переведён декодером за инструкцию)
  выход:       нет; сумма a+b лежит в DS гостя
  функция:     Обработчик ADD 0x20 (эффект ( a b -- a+b )): gpop снимает
               оба слова гостя (меньше двух — ловушка 2), ADD узла
               складывает по модулю 2^64 (коммутативна — без SWAP),
               gpush кладёт сумму (как op_add эталона, t0.uvm.ops);
               кирпич darith (tab.ubrk).
  зависимости: gpop, ADD, gpush

МЕТОД udiv ( -- )
  вход:        нет (gpc уже переведён декодером за инструкцию)
  выход:       нет; частное a/b лежит в DS гостя; делитель 0 — ловушка 1
  функция:     Обработчик UDIV 0x23 (эффект ( a b -- a/b )): gpop
               снимает оба слова гостя (меньше двух — ловушка 2) — при
               ловушке деления оба уже сняты, как у эталона (ds_pop2
               прежде trap), SWAP ставит пару в порядок ( a b ),
               делитель b = 0 — ловушка 1 гостя (STOP с кодом 1, как
               TRAP_DIV0 эталона), иначе UDIV узла даёт целое частное,
               gpush кладёт его (как op_udiv эталона); кирпич darith
               (tab.ubrk).
  зависимости: gpop, SWAP, DUP, EQ, IF, STOP, THEN, UDIV, gpush

  функция:     Обработчик UMOD 0x24 (эффект ( a b -- a%b )): как udiv —

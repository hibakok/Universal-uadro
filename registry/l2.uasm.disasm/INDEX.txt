ИНДЕКС ВЕТВИ l2.uasm.disasm [слой L2]

Индекс генерируется tools/registry_scan.py; вручную не редактировать.
Карточки методов исходного файла — registry/l2.uasm.disasm/<файл>.txt.

- src/l2/disasm.ubrk — методов: 24
  карточки: registry/l2.uasm.disasm/disasm.txt
  описание: Дизассемблер uAsm — собственное воплощение Этапа 4: вход —
            образ UVM в stdin (KEY), выход — текст uAsm в stdout (EMIT),
            код завершения 0 (SPEC/L4-SELFHOST.txt, разделы 4-5).
            Подшаги 1-3: каркас, таблица мнемоник, поле imm64, печать
            десятичного значения и хвост DB. Опкод без поля — строка
            «МНЕМОНИКА»; опкод с полем imm64 — строка «МНЕМОНИКА
            значение» (десятичное слово 0..2^64-1); неизвестный код и
            обрыв поля — останов декодирования: с опкода останова до
            конца входа данные печатаются директивами DB по восемь
            аргументов на строку. Золотой набор SPEC/L4-SELFHOST.txt
            (раздел 6) пройден (tests/test_l2_disasm_gold.py): вывод
            равен эталону disasm байт в байт на каждом образе набора,
            раунд-трип assemble(disasm(B)) == B на собственном выводе;
            сквозной конвейер настоящими процессами. Ветвь закрыта.
- tests/test_l2_disasm.py — методов: 24
  карточки: registry/l2.uasm.disasm/test_l2_disasm.txt
  описание: Тесты подшагов 1-3 ветви l2.uasm.disasm: каркас, таблица
            мнемоник, поле imm64, печать десятичного значения и хвост DB
            (src/l2/disasm.ubrk): сборка настоящей командой compile,
            пустой вход, опкоды без imm64 — по строке на мнемонику,
            инструкции с imm64 — золотая сверка с эталоном disasm байт в
            байт, хвост DB с опкода останова (обрыв поля, неизвестный
            опкод, длины хвоста, устаревшее iv/ii) — эталон байт в байт,
            сквозной прогон настоящими процессами.
- tests/test_l2_disasm_gold.py — методов: 26
  карточки: registry/l2.uasm.disasm/test_l2_disasm_gold.txt
  описание: Подшаг 4 ветви l2.uasm.disasm — золотой набор и закрытие
            ветви: полный золотой набор SPEC/L4-SELFHOST.txt (раздел 6)
            одним файлом: пустой вход, каждый опкод v0.1 отдельно,
            обрывы поля imm64, хвосты данных, смешанные программы,
            образы программ этапов 1-2; для каждого золотого образа —
            вывод собственного дизассемблера равен эталону disasm байт в
            байт и раунд-трип assemble(disasm(B)) == B на собственном
            выводе; TestProcess — сквозной конвейер настоящими
            процессами.

КАРТОЧКИ ФАЙЛА src/l2/disasm.ubrk

Ветвь: l2.uasm.disasm
Слой: L2
Методов: 24
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Дизассемблер uAsm — собственное воплощение Этапа 4: вход —
          образ UVM в stdin (KEY), выход — текст uAsm в stdout (EMIT),
          код завершения 0 (SPEC/L4-SELFHOST.txt, разделы 4-5). Подшаги
          1-3: каркас, таблица мнемоник, поле imm64, печать десятичного
          значения и хвост DB. Опкод без поля — строка «МНЕМОНИКА»;
          опкод с полем imm64 — строка «МНЕМОНИКА значение» (десятичное
          слово 0..2^64-1); неизвестный код и обрыв поля — останов
          декодирования: с опкода останова до конца входа данные
          печатаются директивами DB по восемь аргументов на строку.
          Золотая сверка с эталоном на образах программ этапов 1-2 и
          раунд-трип — подшаг 4.

МЕТОД tstm ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки таблицы мнемоник 0x00-0x07
               (стек)
  функция:     Данные: восемь записей по восемь байтов (NOP PUSH DROP
               DUP SWAP OVER ROT PICK); запись кода c — по адресу tstm +
               c * 8.

МЕТОД tmem ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки таблицы мнемоник 0x10-0x13
               (память)
  функция:     Данные: четыре записи по восемь байтов (LOAD8 LOAD64
               STORE8 STORE64); запись кода c — по адресу tmem + (c -
               0x10) * 8.

МЕТОД tari ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки таблицы мнемоник 0x20-0x2C
               (арифметика)
  функция:     Данные: тринадцать записей по восемь байтов (ADD SUB MUL
               UDIV UMOD NEG SHL SHR SAR AND OR XOR INV); запись кода c
               — по адресу tari + (c - 0x20) * 8.

МЕТОД tcmp ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки таблицы мнемоник 0x30-0x35
               (сравнения)
  функция:     Данные: шесть записей по восемь байтов (EQ NEQ LTU GTU
               LEU GEU); запись кода c — по адресу tcmp + (c - 0x30) *
               8.

МЕТОД tjmp ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки таблицы мнемоник 0x40-0x45
               (переходы)
  функция:     Данные: шесть записей по восемь байтов (JMP JZ JNZ CALL
               RET HALT); запись кода c — по адресу tjmp + (c - 0x40) *
               8.

МЕТОД tsys ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки таблицы мнемоник 0x50
               (система)
  функция:     Данные: одна запись — восемь байтов (SYS); запись кода
               0x50 — по адресу tsys.

МЕТОД tdb ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки «DB » (D, B, пробел, ноль)
  функция:     Данные: префикс строки директивы DB хвоста данных; печать
               — словом prints (до нулевого байта); кирпич dbsep.

МЕТОД scale8 ( idx base -- addr )
  вход:        idx: слово — номер записи в строке таблицы (код - низ
               диапазона)
  вход:        base: слово — адрес первой записи строки таблицы мнемоник
  выход:       addr: слово — адрес записи idx: base + idx * 8
  функция:     Адрес записи таблицы мнемоник (SPEC/L4-SELFHOST.txt,
               раздел 5); кирпич слова rowbase.
  зависимости: SWAP, MUL, ADD

МЕТОД rowbase ( code -- addr 1 | 0 )
  вход:        code: слово — опкод 0..255
  выход:       addr: слово — адрес записи мнемоники (при флаге 1) либо 0
  выход:       flag: слово — 1: код в таблице; 0: код в дыре или за
               таблицей
  функция:     Ищет опкод в шести строках таблицы: диапазоны 0x00-0x07
               (tstm), 0x10-0x13 (tmem), 0x20-0x2C (tari), 0x30-0x35
               (tcmp), 0x40-0x45 (tjmp), 0x50 (tsys); адрес записи =
               база строки + (код - низ) * 8 (SPEC/L4-SELFHOST.txt,
               раздел 5).
  зависимости: LEU, LTU, GTU, scale8, tstm, tmem, tari, tcmp, tjmp, tsys

МЕТОД hasimm ( code -- flag )
  вход:        code: слово — опкод 0..255
  выход:       flag: слово — 1, если за опкодом следует поле imm64,
               иначе 0
  функция:     Признак поля imm64 без таблицы (SPEC/L4-SELFHOST.txt,
               раздел 5): сравнения и диапазоны — коды 0x01, 0x07,
               0x40-0x43, 0x45, 0x50.
  зависимости: EQ, LTU, LEU

МЕТОД keyok ( -- c 1 | 0 )
  вход:        нет (байт входа читается из stdin, KEY)
  выход:       pair: c и флаг 1 — прочитан байт; либо 0 без байта — EOF
  функция:     Читает байт входа (KEY): EOF даёт только флаг 0, байт — c
               и флаг 1; кирпичи чтения поля imm64 (immstep) и хвоста DB
               (dbrest).
  зависимости: KEY

МЕТОД accbyte ( c -- )
  вход:        c: слово — прочитанный байт поля imm64 (0..255)
  выход:       нет; iv получает c * ip, ip — следующую степень 256
  функция:     Накапливает байт little-endian поля imm64: iv = iv + c *
               ip, ip = ip * 256 (SPEC/L4-SELFHOST.txt, раздел 5);
               кирпич immstep.
  зависимости: MUL, ADD, ip, iv

МЕТОД immstep ( -- done )
  вход:        нет (ячейки iv/ip/ii — состояние поля, см. карточки var)
  выход:       done: слово — 0: байт поля прочитан и накоплен; 1: поле
  выход:       прочитано целиком (ii = 8) либо вход кончился (EOF)
  функция:     Один шаг чтения поля imm64: восемь байтов уже прочитаны —
               флаг 1; иначе keyok: байт — accbyte и ii + 1, флаг 0; EOF
               — флаг 1.
  зависимости: keyok, accbyte, ii

МЕТОД getimm ( -- )
  вход:        нет (байты поля читаются из stdin, KEY)
  выход:       нет; iv — значение поля (при ii = 8), ii — число
               прочитанных
  выход:       байтов поля 0..8, ip — степень 256 за последним байтом
  функция:     Читает поле imm64 (SPEC/L4-SELFHOST.txt, раздел 5):
               обнуляет iv, ставит ip = 1 и ii = 0, затем immstep до
               флага готовности; обрыв поля (ii < 8 после цикла)
               распознаёт вызывающий.
  зависимости: iv, ip, ii, immstep

МЕТОД printu ( u -- )
  вход:        u: слово — значение 0..2^64-1
  выход:       нет (цифры выводятся в stdout, EMIT)
  функция:     Печатает десятичное число (SPEC/L4-SELFHOST.txt, раздел
               5): старшие разряды — рекурсивный вызов с частным от UDIV
               10, затем младший разряд — остаток UMOD 10 + '0'; u = 0
               даёт «0».
  зависимости: UDIV, UMOD, ADD, EMIT, printu

МЕТОД dbsep ( -- )
  вход:        нет
  выход:       нет (разделитель выводится в stdout, EMIT)
  функция:     Печатает разделитель перед аргументом директивы DB:
               первый аргумент строки — префикс «DB » (text-строка tdb,
               prints), остальные — пробел (space); кирпич dbstep.
  зависимости: jc, tdb, prints, space

МЕТОД dbstep ( c -- )
  вход:        c: слово — байт данных 0..255
  выход:       нет; аргумент DB выводится в stdout (EMIT)
  функция:     Печатает один аргумент директивы DB: разделитель dbsep и
               десятичное значение printu; ведёт счётчик строки jc:
               восемь аргументов — перевод строки (cr) и сброс счётчика
               (SPEC/L4-SELFHOST.txt, раздел 5: по восемь аргументов на
               строку).
  зависимости: dbsep, printu, jc, cr

МЕТОД dbfstep ( -- done )
  вход:        нет (ячейки iv/ii — прочитанный префикс поля, ik — индекс
               байта)
  выход:       done: слово — 0: байт поля напечатан, индекс движется; 1:
  выход:       все ii байтов префикса напечатаны
  функция:     Один шаг цикла dbfield: ik < ii — байт ik поля печатается
               dbstep (байт k = (iv >> 8k) AND 255: iv — little-endian
               значение прочитанного префикса поля), ik + 1, флаг 0;
               иначе флаг 1.
  зависимости: ik, ii, iv, dbstep

МЕТОД dbfield ( -- )
  вход:        нет (ячейки iv/ii — прочитанный префикс поля imm64)
  выход:       нет; байты префикса поля выводятся аргументами DB
               (dbstep)
  функция:     Печатает байты прочитанного префикса поля imm64 — ii
               байтов little-endian значения iv (SPEC/L4-SELFHOST.txt,
               раздел 5: обрыв поля — хвост DB включает опкод и
               прочитанные байты поля): обнуляет ik и повторяет dbfstep
               до флага готовности.
  зависимости: ik, dbfstep

МЕТОД dbrest ( -- )
  вход:        нет (байты читаются из stdin, KEY)
  выход:       нет; байты выводятся аргументами DB (dbstep)
  функция:     Печатает остаток входа до EOF аргументами директивы DB:
               keyok читает байт — dbstep и продолжение цикла; EOF —
               конец (данные после опкода останова,
               SPEC/L4-SELFHOST.txt, раздел 5).
  зависимости: keyok, dbstep

МЕТОД dbend ( -- )
  вход:        нет (ячейка jc — аргументы текущей строки DB)
  выход:       нет (перевод строки выводится в stdout)
  функция:     Завершает хвост DB: неполная последняя строка (jc > 0) —
               перевод строки (cr); полная строка уже переведена dbstep.
  зависимости: jc, cr

МЕТОД dbtail ( op -- )
  вход:        op: слово — байт опкода останова декодирования 0..255
  выход:       нет; не возвращается: хвост выводится в stdout, затем BYE
  функция:     Хвост DB останова (SPEC/L4-SELFHOST.txt, раздел 5): с
               опкода останова до конца входа данные печатаются
               директивами DB — dbstep печатает опкод, dbfield —
               прочитанные байты поля imm64 (ii байтов little-endian
               значения iv; у останова без поля вызывающий заранее
               обнуляет ii), dbrest — остаток входа, dbend — неполную
               строку; счётчик строки jc обнуляется перед печатью;
               завершает программу (BYE, код 0).
  зависимости: jc, dbstep, dbfield, dbrest, dbend, BYE

МЕТОД dbstop ( op -- )
  вход:        op: слово — байт неизвестного опкода 0..255
  выход:       нет; не возвращается (завершает программу dbtail)
  функция:     Останов декодирования на неизвестном опкоде без поля
               imm64: байтов поля в хвосте нет — обнуляет ii (устаревшие
               iv/ii прежних инструкций не должны попасть в хвост) и
               передаёт опкод в dbtail.
  зависимости: ii, dbtail

МЕТОД main ( -- )
  вход:        нет (вход инструмента — байты stdin, KEY)
  выход:       нет (выход инструмента — байты stdout, EMIT; код
               завершения 0)
  функция:     Цикл дизассемблера: читает байт опкода (KEY); EOF —
               завершение (BYE, директив DB нет). Опкод с полем imm64
               (hasimm): getimm читает поле; обрыв поля (ii < 8) —
               останов: dbtail печатает хвост DB с опкода и прочитанных
               байтов поля; полное поле — строка «МНЕМОНИКА значение»:
               prints, space и десятичное значение iv — printu. Опкод
               без поля — строка «МНЕМОНИКА» (rowbase, prints).
               Неизвестный код — останов декодирования: dbstop (без
               поля) либо dbtail (поле прочитано целиком) — хвост DB с
               опкода до конца входа. Флаги IF снимаются с DS; ветки
               останова не возвращаются (BYE внутри dbtail), успешные
               ветки снимают свою копию опкода словом DROP.
  зависимости: KEY, BYE, rowbase, hasimm, getimm, ii, iv, prints, space,
               cr,, printu, dbtail, dbstop

КАРТОЧКИ ФАЙЛА tools/uvm_devices.py

Ветвь: t0.uvm.bus
Слой: T0
Методов: 10
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Устройства стандартного набора шины UVM v0.3: консоль, таймер,
          блочное хранилище; привязка набора к машине (SPEC/L0-UVM.txt,
          6А.3-6А.4).

МЕТОД ConsoleDev() -> ConsoleDev
  вход:        нет
  выход:       dev: ConsoleDev — устройство консоли без своего состояния
  функция:     Консоль карты портов v1: CON_RX читает байт ввода
               узла-хоста (в конце ввода — все единицы), CON_TX пишет
               младший байт в вывод (SPEC, 6А.3); мост узла-хоста —
               общие кирпичи host_read_byte/host_write_byte (6А.4).
  зависимости: host_read_byte, host_write_byte, trap

МЕТОД TimerDev() -> TimerDev
  вход:        нет
  выход:       dev: TimerDev — устройство таймера
  функция:     Таймер карты портов v1: TMR_CYC читает счётчик шагов
               машины (SPEC, раздел 1), TMR_WALL — миллисекунды
               монотонных часов узла-хоста от точки нуля — момента
               создания устройства (SPEC, 6А.3-6А.4); оба регистра
               только читаются.
  использует:  time.monotonic — монотонные часы узла-хоста (Python)

МЕТОД wall_ms(dev) -> int
  вход:        dev: TimerDev — устройство таймера
  выход:       ms: int — миллисекунды от точки нуля устройства, по
               модулю
  выход:       2^64
  функция:     Даёт текущее значение TMR_WALL: монотонные часы
               узла-хоста минус точка нуля, в миллисекундах, словом по
               модулю 2^64 (SPEC, 6А.3). Недетерминировано — исключение
               детерминизма (раздел 1).
  использует:  time.monotonic — монотонные часы узла-хоста (Python)

МЕТОД word_at(data, pos) -> int
  вход:        data: bytes — байты данных устройства
  вход:        pos: int — позиция младшего байта слова (64-битное слово)
  выход:       w: int — 8 байтов little-endian с позиции pos
  функция:     Собирает слово из байтов данных: за концом данных и в
               хвосте короче восьми байтов читаются нули (SPEC, 6А.3 —
               BLK_DATA).

МЕТОД block_word(dev) -> int
  вход:        dev: BlockDev — устройство хранилища
  выход:       w: int — слово в текущем окне
  функция:     Читает BLK_DATA: слово LE в окне устройства, затем окно
               переносится на 8 вперёд по модулю 2^64 (SPEC, 6А.3).
  зависимости: word_at

МЕТОД BlockDev(data) -> BlockDev
  вход:        data: bytes-like — байты данных устройства; хранится
               копией
  выход:       dev: BlockDev — устройство хранилища, окно в нуле
  функция:     Блочное хранилище карты портов v1 (SPEC, 6А.3): BLK_ADDR
               — окно в байтах (чтение и запись), BLK_DATA — чтение
               слова LE в окне с переносом окна на 8, BLK_SIZE — размер
               данных; запись BLK_DATA/BLK_SIZE — ловушка 9 (хранилище
               v0.3 только читается, 6А.4); данные копируются при
               создании — источник дальше не виден.
  зависимости: block_word, trap

МЕТОД attach_console(m) -> None
  вход:        m: Machine — состояние машины
  выход:       нет
  функция:     Привязывает устройство консоли к портам CON_RX и CON_TX
               (SPEC, 6А.3); кирпич attach_standard.
  зависимости: attach_device, ConsoleDev

МЕТОД attach_timer(m) -> None
  вход:        m: Machine — состояние машины
  выход:       нет
  функция:     Привязывает устройство таймера к портам TMR_CYC и
               TMR_WALL; точка нуля TMR_WALL — момент привязки (SPEC,
               6А.3-6А.4); кирпич attach_standard.
  зависимости: attach_device, TimerDev

МЕТОД attach_block(m, data) -> None
  вход:        m: Machine — состояние машины
  вход:        data: bytes-like — байты данных хранилища
  выход:       нет
  функция:     Привязывает блочное хранилище к портам BLK_ADDR, BLK_DATA
               и BLK_SIZE (SPEC, 6А.3); раннер вызывает по своему
               решению (6А.4, подшаг 5.5).
  зависимости: attach_device, BlockDev

МЕТОД attach_standard(m) -> None
  вход:        m: Machine — состояние машины
  выход:       нет
  функция:     Привязывает стандартный набор раннера — консоль и таймер
               (SPEC, 6А.4): программа рассчитывает на них всегда.
  зависимости: attach_console, attach_timer

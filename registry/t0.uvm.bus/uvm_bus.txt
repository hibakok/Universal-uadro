КАРТОЧКИ ФАЙЛА tools/uvm_bus.py

Ветвь: t0.uvm.bus
Слой: T0
Методов: 3
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Шина устройств UVM v0.3: привязка устройств к портам, чтение и
          запись слова по порту, ловушка 9 (SPEC/L0-UVM.txt, 6А.1).

МЕТОД attach_device(m, dev, ports) -> None
  вход:        m: Machine — состояние машины; шины может не быть
  вход:        dev: object — устройство: read(m, порт) и write(m, порт,
               w)
  вход:        ports: iterable — порты устройства (64-битные слова)
  выход:       нет
  функция:     Привязывает устройство к шине машины на указанные порты;
               шины нет — создаётся пустая; повторная привязка занятого
               порта заменяет прежнее устройство на нём (SPEC, 6А.1).
  использует:  m.bus — таблица «порт -> устройство» машины

МЕТОД bus_read(m, port) -> int
  вход:        m: Machine — состояние машины
  вход:        port: int — порт устройства
  выход:       w: int — 64-битное слово, прочитанное устройством по
               порту
  функция:     Читает слово порта (SPEC, 6А.1): машина без шины или порт
               не привязан — ловушка 9; ответ устройства берётся по
               модулю 2^64 — слово шины всегда слово (раздел 1).
  использует:  m.bus — таблица «порт -> устройство» машины
  зависимости: trap

МЕТОД bus_write(m, port, w) -> None
  вход:        m: Machine — состояние машины
  вход:        port: int — порт устройства
  вход:        w: int — записываемое слово; берётся по модулю 2^64
  выход:       нет
  функция:     Пишет слово в порт (SPEC, 6А.1): машина без шины или порт
               не привязан — ловушка 9; устройству передаётся слово по
               модулю 2^64 — слово шины всегда слово (раздел 1).
  использует:  m.bus — таблица «порт -> устройство» машины
  зависимости: trap

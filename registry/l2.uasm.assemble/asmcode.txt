КАРТОЧКИ ФАЙЛА src/l2/asmcode.ubrk

Ветвь: l2.uasm.assemble
Слой: L2
Методов: 17
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Ассемблер uAsm — кодирование записей в буфер образа:
          use-включение главного файла src/l2/assemble.ubrk
          (SPEC/L4-SELFHOST.txt, раздел 5А, подшаг 6). Собственное
          воплощение эталона tools/uasm_encode.py (encode_record,
          SPEC/L2-UASM.txt, разделы 5-7): инструкция — байт опкода и
          поле imm64 little-endian, DB — по байту на аргумент, DW — по
          слову little-endian, DS/DZ — декодированные байты строкового
          литерала (DZ добавляет байт 0). Значения операндов и
          аргументов — числовые литералы (диапазон -2^63..2^64-1,
          отрицательные по модулю 2^64) либо имена из таблицы символов
          прохода 1 (ссылки вперёд уже разрешены); ошибки значений —
          «uAsm: строка N: текст» и код 16 (fail/failx главного файла).
          Образ длиннее 64 КиБ — «образ слишком большой» (контракт
          инструмента, SPEC/ L4-SELFHOST.txt, раздел 5А; у эталона
          лимита нет).

               L4-SELFHOST.txt, раздел 5А: 64 КиБ); печать — fail.

  функция:     Данные: текст ошибки аргумента DB вне 0..255

МЕТОД tunkname ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки «неизвестное имя » (UTF-8 + 0)
  функция:     Данные: текст ошибки имени, которого нет в таблице

МЕТОД putbyte ( c -- )
  вход:        c: слово — байт 0..255
  выход:       нет; не возвращается при ошибке: байт не помещается в
               буфер
  выход:       образа — «образ слишком большой», код 16
  функция:     Пишет байт c в буфер образа по адресу vc (STORE8) и
               двигает курсор vc на байт (SPEC/L4-SELFHOST.txt, раздел
               5А: буфер образа 64 КиБ, imgbase..imglimit); кирпич
               кодирования всех видов записей.
  зависимости: vc, imglimit, timg, fail, LTU, not, STORE8, ADD,
               STORE64,, LOAD64, IF, THEN

МЕТОД putword ( v -- )
  вход:        v: слово — значение 0..2^64-1
  выход:       нет; не возвращается при ошибке: восемь байтов не
               помещаются
  выход:       в буфер образа — «образ слишком большой», код 16
  функция:     Пишет слово v восемью байтами little-endian в буфер
               образа с адреса vc (wword) и ставит курсор за восьмым
               байтом (SPEC/ L2-UASM.txt, разделы 5-6: поле imm64 и
               аргумент DW); кирпич кодирования инструкции и DW.
  зависимости: vc, imglimit, timg, fail, wword, GTU, ADD, LOAD64,
               STORE64,, IF, THEN

МЕТОД resval ( a l -- v )
  вход:        a: слово — адрес первого байта операнда либо аргумента
  вход:        l: слово — число байтов операнда либо аргумента
  выход:       v: слово — значение 0..2^64-1; не возвращается при
               ошибке:
  выход:       «литерал вне диапазона», «неизвестное имя X», «плохой
  выход:       литерал X» — код 16
  функция:     Разрешает операнд в значение (SPEC/L2-UASM.txt, разделы
               5-6, resolve_value эталона tools/uasm_encode.py):
               числовой литерал numlit — значение lexv по модулю 2^64
               (отрицательные обёрнуты), kind 2 — «литерал вне
               диапазона»; имя (isname) — symfind по таблице символов,
               значение записи — loadle; не найдено — «неизвестное имя
               X» (X — текст операнда; клетки ka/kl хранят кандидата и
               после неудачного поиска); ни литерал, ни имя — «плохой
               литерал X»; кирпич кодирования инструкции и аргументов
               DB/DW.
  зависимости: numlit, lexv, isname, symfind, loadle, ka, kl, trange,,
               tbadlitx, tunkname, fail, failx, EQ, not, DUP, DROP,
               OVER,, IF, THEN, EXIT, LOAD64

МЕТОД dbstep ( -- done )
  вход:        нет (клетки ai, argc — состояние кодирования DB)
  выход:       done: слово — 0: аргумент закодирован байтом, кодирование
  выход:       продолжается; 1: аргументов больше нет (ai достиг argc)
  функция:     Один шаг кодирования DB (SPEC/L2-UASM.txt, раздел 6,
               encode_db эталона): nextarg даёт слово-аргумент, resval —
               значение; значение больше 255 — «байт вне диапазона»
               (fail, код 16; отрицательные уже обёрнуты по модулю 2^64
               — резольвер оборачивает, byte_of эталона отклоняет);
               иначе putbyte пишет байт, ai растёт; кирпич emitdb.
  зависимости: ai, argc, nextarg, resval, tbyte, fail, putbyte, GEU,
               GTU,, DUP, IF, THEN, EXIT, ADD, STORE64, LOAD64

МЕТОД esstep ( -- done )
  вход:        нет (клетки ep, ee — состояние скана литерала)
  выход:       done: слово — 0: байт декодирован и записан в буфер
               образа;
  выход:       1: закрывающая кавычка достигнута (либо неверный escape —
  выход:       невозможен: литерал уже проверен разбором строки)
  функция:     Один шаг декодирования строкового литерала
               (SPEC/L2-UASM.txt, раздел 4 — escape как parse_string
               эталона; кодирование — раздел 6): байт «\» (92) требует
               escape из streval — один декодированный байт (putbyte),
               позиция растёт на два; прочие байты (многобайтовый UTF-8
               дословно, по байту) — putbyte и позиция на один; позиция
               на закрывающей кавычке (ee) — конец; кирпич emitstr.
  зависимости: ep, ee, putbyte, streval, GEU, EQ, LOAD8, LOAD64, ADD,,
               STORE64, DUP, DROP, IF, ELSE, THEN, EXIT

МЕТОД emitstr ( a l -- )
  вход:        a: слово — адрес первого байта литерала (открывающая
               кавычка)
  вход:        l: слово — число байтов литерала вместе с кавычками
  выход:       нет; декодированные байты пишутся в буфер образа
  функция:     Декодирует строковый литерал в буфер образа
               (SPEC/L2-UASM.txt, раздел 6): ep — первый байт внутри
               кавычек (a + 1), ee — закрывающая кавычка (a + l - 1);
               esstep до конца; кирпичи emitds и emitdz.
  зависимости: ep, ee, esstep, ADD, SUB, OVER, STORE64, BEGIN, UNTIL

МЕТОД emitinstr ( -- )
  вход:        нет (клетки rc — код мнемоники; ra, rl — операнд-текст)
  выход:       нет; инструкция пишется в буфер образа (ошибки значения
  выход:       операнда и ёмкости — код 16, образ не выводится)
  функция:     Кодирует инструкцию (SPEC/L2-UASM.txt, раздел 5,

               (putword); у остальных опкодов — только байт опкода
               (операнда нет — проверил doinstr); кирпич p2step.
  зависимости: rc, ra, rl, hasimm, resval, putbyte, putword, LOAD64,
               IF,, ELSE, THEN

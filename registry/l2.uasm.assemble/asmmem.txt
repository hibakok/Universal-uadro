КАРТОЧКИ ФАЙЛА src/l2/asmmem.ubrk

Ветвь: l2.uasm.assemble
Слой: L2
Методов: 11
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Ассемблер uAsm — память инструмента: use-включение главного
          файла src/l2/assemble.ubrk (SPEC/L4-SELFHOST.txt, раздел 5А).
          Раскладка ОЗУ — восемь слов-адресов четырёх буферов; кирпичи
          чтения stdin в буфер источника: keyok, roomok, storebyte.

МЕТОД srcbase ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес 0x10000, первый байт буфера источника
  функция:     Раскладка ОЗУ: буфер источника (текст uAsm из stdin)
               начинается с адреса 0x10000 и занимает 512 КиБ.

МЕТОД srclimit ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес 0x90000, за последним байтом буфера
  выход:       источника
  функция:     Раскладка ОЗУ: предел буфера источника; вход длиннее —
               «вход слишком большой» и код 16 (SPEC/L4-SELFHOST.txt,
               раздел 5А).

  вход:        нет

  функция:     Раскладка ОЗУ: буфер образа (собираемый образ UVM) — 64

МЕТОД keyok ( -- c 1 | 0 )
  вход:        нет (байт входа читается из stdin, KEY)
  выход:       pair: c и флаг 1 — прочитан байт; либо 0 без байта — EOF
  функция:     Читает байт входа инструмента (KEY): EOF даёт только флаг
               0, байт — c и флаг 1; кирпич readstep главного файла
               assemble.ubrk.
  зависимости: KEY

МЕТОД roomok ( cur -- flag )
  вход:        cur: слово — адрес следующего байта буфера источника
  выход:       flag: слово — 1: байт влезает (cur < srclimit); 0: буфер
               полон
  функция:     Проверка ёмкости буфера источника перед записью байта:
               вход сверх 512 КиБ обязан закончиться диагностикой «вход
               слишком большой» и кодом 16 (SPEC/L4-SELFHOST.txt, раздел
               5А).
  зависимости: srclimit, LTU

МЕТОД storebyte ( cur c -- cur' )
  вход:        cur: слово — адрес следующего байта буфера источника
  вход:        c: слово — прочитанный байт входа 0..255
  выход:       cur': слово — адрес следующего байта буфера после записи
  функция:     Записывает байт c в буфер источника по адресу cur
               (STORE8) и возвращает cur + 1; кирпич readstep главного
               файла assemble.ubrk.
  зависимости: OVER, STORE8, ADD

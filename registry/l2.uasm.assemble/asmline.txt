КАРТОЧКИ ФАЙЛА src/l2/asmline.ubrk

Ветвь: l2.uasm.assemble
Слой: L2
Методов: 22
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Ассемблер uAsm — разбор строки в запись: use-включение
          главного файла src/l2/assemble.ubrk (SPEC/L4-SELFHOST.txt,
          раздел 5А, подшаг 4). Собственное воплощение эталона
          tools/uasm_line.py (parse_line, SPEC/L2-UASM.txt, разделы
          3-7): порядок разбора строки — метка «имя:», мнемоника либо
          директива данных, константа «имя = литерал», иначе
          «неизвестная мнемоника X»; ошибки разбора строки — диагностика
          «uAsm: строка N: текст» и код 16 (fail/failx главного файла).
          Запись — в var-ячейках (раздел 5А, механика): rk — вид, rn —
          длина имени, rv — значение константы, rc — код мнемоники;
          слово и операнд — wa/wl и ra/rl, аргументы DB/DW — argc, длина
          литерала DS/DZ — sl (кирпичи asmwords/asmlex). Листинг записей
          «N:V …» (reclist главного файла) — промежуточный вывод
          подшага, заменяемый проходами подшагов 5-6.

  выход:       нет; не возвращается при ошибке; иначе rk = 3, rc = code,

МЕТОД direq ( -- k 1 | 0 )
  вход:        нет (клетки wa, wl — первое слово строки)
  выход:       pair: k и 1 — слово — директива данных, k = 4 (DB), 5
               (DW),
  выход:       6 (DS), 7 (DZ) — вид записи директивы; 0 — не директива
  функция:     Признак и вид директивы данных (SPEC/L2-UASM.txt, разделы
               6 и 7): слово из двух байтов — «D» (68) и «B» (66), «W»
               (87), «S» (83) либо «Z» (90); роль слова определяет
               позиция в строке (раздел 3), имя метки «DS:» директивой
               не считается; кирпичи parseline и isdbdw.
  зависимости: wa, wl, EQ, not, DUP, DROP, IF, ELSE, THEN, EXIT, LOAD8,
               ADD

МЕТОД parseconst ( s cut -- )
  вход:        s: слово — адрес начала чистой строки (= wa)
  вход:        cut: слово — адрес знака «=» вне кавычек в строке
  выход:       нет; не возвращается при ошибке; иначе rk = 2, rn — длина
  выход:       имени, rv — значение константы по модулю 2^64
  функция:     Разбирает константу «имя = литерал» (SPEC/L2-UASM.txt,
               разделы 3-4 и 7, parse_const эталона): левая часть —
               rtrim [s, cut), обязана быть именем (isname), иначе
               «плохое имя» (проверка прежде литерала — порядок ошибок
               эталона); правая — ltrim [cut+1, конец строки): numlit
               решает литерал — kind 0 «плохой литерал [X]» (badlit),
               kind 2 «литерал вне диапазона», kind 1 — значение rv по
               модулю 2^64 (отрицательные оборачивает numlit); имя —
               [wa, rn) (левая часть без концевых пробелов).
  зависимости: ra, rl, rk, rn, rv, ltrim, rtrim, numlit, isname,
               badlit,, tbadname, trange, fail, ADD, SUB, OVER, DUP,
               DROP, SWAP,, STORE64, LOAD64, EQ, not, IF, THEN, EXIT

МЕТОД parseline ( -- )
  вход:        нет (клетки wa/wl — первое слово, ra/rl — остаток чистой
  вход:        строки; для DB/DW заполнены argc и буфер аргументов)
  выход:       нет; не возвращается при ошибке разбора; иначе клетки
               записи
  выход:       rk/rn/rv/rc (вид, имя, значение, код) готовы для проходов
  функция:     Разбирает строку в запись по порядку раздела 7 SPEC/
               L2-UASM.txt (parse_line эталона): слово с двоеточием —
               метка (dolabel); мнемоника — инструкция (doinstr);
               директива данных — dodata; знак «=» вне кавычек в чистой
               строке [wa, ra+rl) — константа (parseconst; findch, «=» =
               61); иначе — «неизвестная мнемоника X» (X — слово,
               failx). Чистая строка целиком восстанавливается из
               клеток: начало — wa, конец — ra+rl.
  зависимости: endlab, dolabel, mnem, doinstr, direq, dodata,
               parseconst,, wa, wl, ra, rl, findch, tunk, failx, ADD,
               DUP, DROP, EQ,, IF, THEN, EXIT

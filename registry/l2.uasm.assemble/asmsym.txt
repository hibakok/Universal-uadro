КАРТОЧКИ ФАЙЛА src/l2/asmsym.ubrk

Ветвь: l2.uasm.assemble
Слой: L2
Методов: 19
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Ассемблер uAsm — таблица символов: use-включение главного
          файла src/l2/assemble.ubrk (SPEC/L4-SELFHOST.txt, раздел 5А,
          подшаг 5). Собственное воплощение эталона
          tools/uasm_symbols.py: единое пространство имён меток и
          констант. Хранилище — записи «значение 8 байтов LE + имя +
          байт 0» подряд с адреса 0xA0000 (раскладка asmmem.ubrk),
          курсор sc — конец занятой области. Определение symdef ищет имя
          прежде записи: повторное — «повторное определение имени X»;
          имя длиннее 63 байтов — «слишком длинное имя»; запись за
          предел 0xF0000 — «таблица символов переполнена»
          (SPEC/L4-SELFHOST.txt, раздел 5А). Поиск сравнивает кандидата
          с именами записей: кандидат за концом дополняется нулём, имя
          записи завершено нулём — совпадение, когда равны все l+1
          позиции (симметрия с mstep/entrymatch asmmnem.ubrk). Чтение
          слова LE — loadle: кирпич листинга символов главного файла
          (подшаг 5) и кодирования (подшаг 6).

МЕТОД symcmpstep ( -- done )
  вход:        нет (клетки ka, kl, kr, ki — состояние сравнения)
  выход:       done: слово — 0: позиция ki совпала, сравнение
               продолжается;
  выход:       1: расхождение байтов либо сравнены все kl+1 позиций
  функция:     Один шаг сравнения имени-кандидата ka/kl с именем записи
               kr (SPEC/L4-SELFHOST.txt, раздел 5А): байт кандидата на
               позиции ki — из [ka, ka+kl), на позиции kl — ноль (имя
               записи завершено нулём, поэтому равенство всех kl+1
               позиций — точное совпадение имён: более короткое имя
               записи даст не-нуль кандидата, более длинное — свой
               не-нуль); байт записи — по адресу kr + 8 + ki;
               расхождение — стоп.
  зависимости: ka, kl, kr, ki, GTU, LTU, ADD, LOAD8, NEQ, STORE64

МЕТОД symrecmatch ( -- ф )
  вход:        нет (клетка kr — запись; ka, kl — кандидат)
  выход:       ф: слово — 1: имя записи kr равно кандидату ka/kl; 0:
               иначе
  функция:     Сравнивает кандидата с записью kr целиком (SPEC/
               L4-SELFHOST.txt, раздел 5А): symcmpstep от ki = 0;
               совпадение — ki достиг kl+1 (все позиции равны); кирпич
               symfstep.
  зависимости: ka, kl, ki, symcmpstep, EQ, ADD

  зависимости: zn, LOAD8, EQ, ADD, STORE64

МЕТОД symfstep ( -- done )
  вход:        нет (клетки kr, sc, ka, kl — состояние скана)
  выход:       done: слово — 0: запись kr не совпала, скан продолжается;

  выход:       совпадение (kr — запись) либо таблица исчерпана
  функция:     Один шаг скана таблицы (SPEC/L4-SELFHOST.txt, раздел 5А):

МЕТОД symfind ( a l -- r 1 | 0 )
  вход:        a: слово — адрес первого байта имени
  вход:        l: слово — число байтов имени
  выход:       pair: r и 1 — имя найдено, r — адрес записи (поля
               значения);
  выход:       либо 0 — имени в таблице нет
  функция:     Ищет имя в таблице символов (SPEC/L2-UASM.txt, разделы 3
               и 7, symbol_get эталона): ka/kl — кандидат, kr идёт от
               symbase по записям до совпадения либо конца (sc); клетки
               ka/kl хранят кандидата и после выхода — их читает
               symappend; кирпичи symdef (проход 1) и разрешения имён
               (проход 2, подшаг 6).
  зависимости: ka, kl, kr, sc, symbase, symfstep, LTU, IF, ELSE, THEN

МЕТОД symroom ( l -- )
  вход:        l: слово — длина имени определяемого символа
  выход:       нет; не возвращается при ошибке: запись l + 9 байтов не
  выход:       помещается в таблицу — «таблица символов переполнена»,
               код 16
  функция:     Проверка ёмкости таблицы символов (SPEC/L4-SELFHOST.txt,
               раздел 5А): запись занимает 8 (значение) + l (имя) + 1
               (ноль) байтов; выход за symlimit — ошибка входа
               инструмента (fail); кирпич symappend.
  зависимости: sc, symlimit, tsymfull, fail, ADD, GTU, IF, THEN

МЕТОД wwordstep ( -- done )
  вход:        нет (клетки wv, wp, wi — состояние записи)
  выход:       done: слово — 0: байт записан, запись продолжается; 1:

               symcopy — имя и ноль; кирпич symdef.

  вход:        l: слово — число байтов имени
  вход:        v: слово — значение символа (метке — адрес записи,

  вход:        значение литерала по модулю 2^64)

КАРТОЧКИ ФАЙЛА src/l2/asmmnem.ubrk

Ветвь: l2.uasm.assemble
Слой: L2
Методов: 12
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Ассемблер uAsm — таблица мнемоник и поиск кода по мнемонике:
          use-включение главного файла src/l2/assemble.ubrk
          (SPEC/L4-SELFHOST.txt, раздел 5А, подшаг 2). Шесть text-строк
          по диапазонам кодов — те же, что у дизассемблера
          l2.uasm.disasm (SPEC/L4-SELFHOST.txt, раздел 5); запись —
          восемь байтов: мнемоника, дополненная нулями; слово mnem ищет
          код первого слова строки сравнением с записями строк: код =
          низ диапазона + номер записи; слово hasimm — признак поля
          imm64 опкода (подшаг 4).

МЕТОД tstm ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки таблицы мнемоник 0x00-0x07
               (стек)
  функция:     Данные: восемь записей по восемь байтов (NOP PUSH DROP
               DUP SWAP OVER ROT PICK); запись кода c — по адресу tstm +
               c * 8.

МЕТОД tmem ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки таблицы мнемоник 0x10-0x13
               (память)
  функция:     Данные: четыре записи по восемь байтов (LOAD8 LOAD64
               STORE8 STORE64); запись кода c — по адресу tmem + (c -
               0x10) * 8.

МЕТОД tari ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки таблицы мнемоник 0x20-0x2C
  выход:       (арифметика)
  функция:     Данные: тринадцать записей по восемь байтов (ADD SUB MUL
               UDIV UMOD NEG SHL SHR SAR AND OR XOR INV); запись кода c
               — по адресу tari + (c - 0x20) * 8.

МЕТОД tcmp ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки таблицы мнемоник 0x30-0x35
  выход:       (сравнения)
  функция:     Данные: шесть записей по восемь байтов (EQ NEQ LTU GTU
               LEU GEU); запись кода c — по адресу tcmp + (c - 0x30) *
               8.

МЕТОД tjmp ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки таблицы мнемоник 0x40-0x45
  выход:       (переходы)
  функция:     Данные: шесть записей по восемь байтов (JMP JZ JNZ CALL
               RET HALT); запись кода c — по адресу tjmp + (c - 0x40) *
               8.

МЕТОД tsys ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки таблицы мнемоник 0x50
               (система)
  функция:     Данные: одна запись — восемь байтов (SYS); запись кода
               0x50 — по адресу tsys.

МЕТОД mstep ( -- done )
  вход:        нет (клетки mi, ri, rb — состояние сравнения; wa, wl —
               слово)
  выход:       done: слово — 0: байты равны, mi движется; 1: расхождение
               байтов
  выход:       либо все восемь позиций записи сравнены
  функция:     Один шаг сравнения слова wa/wl с записью ri строки rb:
               байт слова (mi < wl — байт по адресу wa + mi, иначе 0)
               сравнивается с байтом записи rb + ri * 8 + mi;
               расхождение — стоп (mi < 8 означает несовпадение);
               читаются только восемь байтов записи.
  зависимости: mi, ri, rb, wa, wl, GEU, LTU, EQ, NEQ, ADD, MUL, LOAD8

МЕТОД entrymatch ( -- ф )
  вход:        нет (клетки ri, rb — запись диапазона; wa, wl — слово)
  выход:       ф: слово — 1: слово совпало с записью ri (все восемь
               позиций
  выход:       сравнены и длина слова не больше восьми); 0: иначе
  функция:     Сравнивает слово wa/wl с записью ri диапазона rb (SPEC/
               L4-SELFHOST.txt, раздел 5А: сравнение слова исходника с
               записями строк): mstep от mi = 0; слово длиннее восьми
               байтов совпадать не может — ни одна мнемоника не длиннее
               семи, запись с нулевым байтом слову не равна.
  зависимости: mi, ri, rb, wa, wl, mstep, EQ, LEU, AND

МЕТОД rstep ( -- done )
  вход:        нет (клетки rb, rcount, ri — состояние сканирования
               диапазона)
  выход:       done: слово — 0: запись ri не совпала, ri движется; 1:
               совпало
  выход:       (ri — номер записи) либо диапазон исчерпан
  функция:     Один шаг сканирования диапазона таблицы: entrymatch
               проверяет запись ri; совпадение — стоп, иначе ri + 1; ri
               = rcount — стоп без совпадения; кирпич rangematch.
  зависимости: ri, rcount, entrymatch, LTU, not

МЕТОД rangematch ( base low count -- code 1 | 0 )
  вход:        base: слово — адрес первой записи строки таблицы
  вход:        low: слово — низ диапазона кодов строки
  вход:        count: слово — число записей строки
  выход:       pair: code и 1 — слово совпало с записью, code = low +
               номер
  выход:       записи; либо 0 — в строке совпадения нет
  функция:     Сканирует строку таблицы мнемоник (SPEC/L4-SELFHOST.txt,
               раздел 5А: код = низ диапазона + номер записи): rstep,
               пока не найдёт запись либо не исчерпает диапазон.
  зависимости: rb, rlow, rcount, ri, rstep, LTU, ADD

МЕТОД mnem ( -- code 1 | 0 )
  вход:        нет (клетки wa, wl — первое слово строки)
  выход:       pair: code и 1 — слово — мнемоника опкода, code — её код;
               либо
  выход:       0 — слово не мнемоника (метка, директива, имя, мусор)
  функция:     Поиск кода по мнемонике (SPEC/L4-SELFHOST.txt, раздел
               5А): шесть строк таблицы по диапазонам — 0x00-0x07
               (tstm), 0x10-0x13 (tmem), 0x20-0x2C (tari), 0x30-0x35
               (tcmp), 0x40-0x45 (tjmp), 0x50 (tsys); директивы
               DB/DW/DS/DZ — не опкоды, их разбирает запись строки
               (asmline.ubrk, подшаг 4); кирпич parseline.
  зависимости: tstm, tmem, tari, tcmp, tjmp, tsys, rangematch, DUP, IF

МЕТОД hasimm ( code -- flag )
  вход:        code: слово — опкод 0..255
  выход:       flag: слово — 1, если за опкодом следует поле imm64,
               иначе 0
  функция:     Признак поля imm64 без таблицы (SPEC/L4-SELFHOST.txt,
               раздел 5А: как hasimm дизассемблера, раздел 5): сравнения
               и диапазоны — коды 0x01, 0x07, 0x40-0x43, 0x45, 0x50
               (PUSH, PICK, JMP, JZ, JNZ, CALL, HALT, SYS —
               SPEC/L2-UASM.txt, раздел 5); кирпич разбора инструкции
               (asmline.ubrk, подшаг 4).
  зависимости: EQ, LTU, LEU, DUP, DROP, IF, EXIT, THEN

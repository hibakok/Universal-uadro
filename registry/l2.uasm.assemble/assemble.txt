КАРТОЧКИ ФАЙЛА src/l2/assemble.ubrk

Ветвь: l2.uasm.assemble
Слой: L2
Методов: 17
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Ассемблер uAsm — собственное воплощение Этапа 4: вход — текст
          uAsm в stdin (KEY), выход — образ UVM в stdout (EMIT); код 0 —
          успех, 16 — ошибка входа (SPEC/L4-SELFHOST.txt, разделы 4 и
          5А). Подшаг 1 (каркас и память): use-включение asmmem.ubrk —
          вход читается целиком в буфер источника 512 КиБ (readstep),
          вход сверх лимита — строка «вход слишком большой» и код 16.
          Подшаг 2 (строки и слова): use-включения asmwords.ubrk
          (деление буфера на строки, чистка строки, первое слово,
          аргументы парами) и asmmnem.ubrk (таблица мнемоник и поиск
          кода). Подшаг 3 (литералы и имена): use-включение asmlex.ubrk
          — числовые формы, минус, диапазон, имена и скан строковых
          литералов DS/DZ; листинг «N:слово[=код] …» теперь с
          лексическими пометами аргументов (lexlist) и сканом литерала
          DS/DZ (dsline) — промежуточное поведение, заменяемое разбором
          записей в подшаге 4. Записи, символы и проходы — подшаги 4-7
          (SPEC/ L4-SELFHOST.txt, раздел 5А).

МЕТОД readstep ( cur -- cur' done )
  вход:        cur: слово — адрес следующего байта буфера источника
  выход:       cur': слово — адрес следующего байта после шага
  выход:       done: слово — 0: байт прочитан и записан в буфер; 1: EOF
  функция:     Один шаг чтения stdin в буфер источника
               (SPEC/L4-SELFHOST.txt, раздел 5А): keyok читает байт;
               байт при наличии места (roomok) — storebyte пишет его,
               шаг возвращает 0; буфер полон — biginput (не
               возвращается); EOF — 1, курсор не меняется.
  зависимости: keyok, roomok, storebyte, biginput

МЕТОД printu ( u -- )
  вход:        u: слово — значение 0..2^64-1
  выход:       нет (цифры выводятся в stdout, EMIT)
  функция:     Печатает десятичное число (SPEC/L4-SELFHOST.txt, раздел
               5А, как printu дизассемблера): старшие разряды —
               рекурсивный вызов с частным от UDIV 10, затем младший
               разряд — остаток UMOD 10 + '0'; u = 0 даёт «0»; кирпич
               листинга и диагностики fail.
  зависимости: UDIV, UMOD, ADD, EMIT, printu

  вход:        a: слово — адрес текста ошибки (Z-строка)

МЕТОД isdsdz ( -- ф )
  вход:        нет (клетки wa, wl — первое слово строки)
  выход:       ф: слово — 1: первое слово — директива DS или DZ; 0:
               иначе
  функция:     Признак строки директивы данных DS/DZ (SPEC/L2-UASM.txt,
               раздел 6): слово из двух байтов — «D» (68) и «S» (83)
               либо «Z» (90); роль слова определяет позиция в строке
               (раздел 3), имя метки «DS:» директивой не считается;
               директива берёт остаток строки целиком — строковый
               литерал, а не слова-аргументы; кирпичи doline и listline.
  зависимости: wa, wl, EQ, not, LOAD8, LOAD64, ADD, DUP, DROP, IF, EXIT,
               THEN

МЕТОД lexmark ( a l -- )
  вход:        a: слово — адрес первого байта слова-аргумента
  вход:        l: слово — число байтов слова-аргумента
  выход:       нет (пометка выводится в stdout, EMIT/printu)
  функция:     Печатает лексическую пометку слова-аргумента (листинг
               подшага 3): числовой литерал — «#» и значение по модулю
               2^64 (numlit, lexv, printu), цифры верны, но вне
               диапазона -2^63..2^64-1 — «!» (33), имя — «*» (42),
               прочее — «?» (63); классификация — эталон
               tools/uasm_lex.py (parse_number, in_literal_range,
               is_name).
  зависимости: numlit, isname, lexv, printu, EMIT, LOAD64, EQ, DUP,
               DROP,, OVER, IF, ELSE, THEN

  выход:       done: слово — 0: аргумент с пометкой выведен; 1:

  зависимости: ai, argc, argbase, LTU, not, MUL, ADD, LOAD64, space,

МЕТОД dsline ( -- )
  вход:        нет (клетки ra, rl — остаток строки после DS/DZ)
  выход:       нет (остаток и пометка выводятся в stdout)
  функция:     Печатает литерал директивы DS/DZ (листинг подшага 3):

МЕТОД listline ( -- )
  вход:        нет (клетки ln, wa, wl, argc, ra, rl и буфер аргументов —
               строка)
  выход:       нет (строка листинга выводится в stdout)
  функция:     Промежуточное поведение подшагов 2-3
               (SPEC/L4-SELFHOST.txt, раздел 5А; заменяется разбором
               строки в запись в подшаге 4): печатает строку листинга
               «N:слово[=код] …» — номер строки (printu), двоеточие,
               первое слово (printw), код мнемоники после «=» (mnem,
               printu); дальше DS/DZ — остаток строки целиком со сканом
               литерала (dsline), иначе — аргументы с лексическими
               пометками (lexlist); перевод строки в конце; пустые
               строки и комментарии молчат (их отсеивает doline).
  зависимости: ln, printu, wa, wl, printw, mnem, isdsdz, dsline,
               lexlist, cr,, EMIT

МЕТОД doline ( s q -- )
  вход:        s: слово — адрес первого байта строки буфера
  вход:        q: слово — адрес за последним байтом строки (на LF либо
               be)
  выход:       нет (строка обрабатывается; вывод подшага 3 — listline)
  функция:     Обрабатывает одну строку (SPEC/L4-SELFHOST.txt, раздел
               5А): снимает концевые CR (crstep), отрезает комментарий
               «;» вне кавычек (findsemi), снимает крайние пробелы и
               табуляции (rtrim, ltrim); пустая строка или комментарий —
               тишина; иначе splitword (первое слово и остаток); буфер
               аргументов заполняется только для не DS/DZ строк (isdsdz:
               литерал DS/DZ берёт остаток целиком, SPEC/L2-UASM.txt,
               раздел 6), затем listline. Подшаг 4 заменит listline
               разбором строки в запись.
  зависимости: crstep, findsemi, rtrim, ltrim, LTU, not, splitword,
               isdsdz,, splitargs, listline

МЕТОД main ( -- )
  вход:        нет (вход инструмента — байты stdin, KEY)
  выход:       нет (выход подшага 3 — листинг строк в stdout, EMIT; код
  выход:       завершения 0 — успех, 16 — ошибка входа)
  функция:     Каркас ассемблера (SPEC/L4-SELFHOST.txt, раздел 5А):

               4-6.
  зависимости: srcbase, readstep, be, bp, ln, linestep, BYE

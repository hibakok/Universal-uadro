КАРТОЧКИ ФАЙЛА src/l2/assemble.ubrk

Ветвь: l2.uasm.assemble
Слой: L2
Методов: 14
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Ассемблер uAsm — собственное воплощение Этапа 4: вход — текст
          uAsm в stdin (KEY), выход — образ UVM в stdout (EMIT); код 0 —
          успех, 16 — ошибка входа (SPEC/L4-SELFHOST.txt, разделы 4 и
          5А). Подшаг 1 (каркас и память): use-включение asmmem.ubrk —
          вход читается целиком в буфер источника 512 КиБ (readstep),
          вход сверх лимита — строка «вход слишком большой» и код 16.
          Подшаг 2 (строки и слова): use-включения asmwords.ubrk
          (деление буфера на строки, чистка строки, первое слово,
          аргументы парами) и asmmnem.ubrk (таблица мнемоник и поиск
          кода); проход linestep печатает промежуточный листинг
          «N:слово[=код] аргументы» — поведение подшага, заменяемое
          разбором записей и сборкой образа в подшагах 3-6. Литералы,
          записи, символы и проходы — подшаги 3-7 (SPEC/L4-SELFHOST.txt,
          раздел 5А).

МЕТОД tbig ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки «вход слишком большой» (UTF-8
               + 0)
  функция:     Данные: текст диагностики переполнения буфера источника —
               единственная диагностика без номера строки
               (SPEC/L4-SELFHOST.txt, раздел 5А); печать — словом
               prints.

МЕТОД biginput ( -- )
  вход:        нет
  выход:       нет; не возвращается: строка выводится в stdout, затем
               программа
  выход:       завершается кодом 16
  функция:     Диагностика переполнения буфера источника
               (SPEC/L4-SELFHOST.txt, раздел 5А): печатает «вход слишком
               большой» с переводом строки и завершает программу словом
               QUIT (HALT 16 — ошибка входа инструмента,
               SPEC/L3-UBRICK.txt, раздел 4.1).
  зависимости: tbig, prints, cr, QUIT

МЕТОД readstep ( cur -- cur' done )
  вход:        cur: слово — адрес следующего байта буфера источника
  выход:       cur': слово — адрес следующего байта после шага
  выход:       done: слово — 0: байт прочитан и записан в буфер; 1: EOF
  функция:     Один шаг чтения stdin в буфер источника
               (SPEC/L4-SELFHOST.txt, раздел 5А): keyok читает байт;
               байт при наличии места (roomok) — storebyte пишет его,
               шаг возвращает 0; буфер полон — biginput (не
               возвращается); EOF — 1, курсор не меняется.
  зависимости: keyok, roomok, storebyte, biginput

МЕТОД printu ( u -- )
  вход:        u: слово — значение 0..2^64-1
  выход:       нет (цифры выводятся в stdout, EMIT)
  функция:     Печатает десятичное число (SPEC/L4-SELFHOST.txt, раздел
               5А, как printu дизассемблера): старшие разряды —
               рекурсивный вызов с частным от UDIV 10, затем младший
               разряд — остаток UMOD 10 + '0'; u = 0 даёт «0»; кирпич
               listline и диагностики fail.
  зависимости: UDIV, UMOD, ADD, EMIT, printu

МЕТОД pwstep ( -- done )
  вход:        нет (клетки pa, pl — состояние печати)
  выход:       done: слово — 0: байт выведен; 1: байтов больше нет
  функция:     Один шаг печати слова: pl = 0 — стоп; байт по адресу pa —
               EMIT, pa + 1, pl - 1; кирпич printw.
  зависимости: pa, pl, EQ, LOAD8, EMIT, ADD, SUB

МЕТОД printw ( a l -- )
  вход:        a: слово — адрес первого байта слова
  вход:        l: слово — число байтов слова
  выход:       нет (байты слова выводятся в stdout, EMIT)
  функция:     Печатает l байтов с адреса a: слова листинга и аргументы
               (listline), слова диагностик подшагов 4-7.
  зависимости: pa, pl, pwstep

МЕТОД tuasm ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки «uAsm: строка » (UTF-8 + 0)
  функция:     Данные: префикс диагностической строки ассемблера (SPEC/
               L4-SELFHOST.txt, раздел 5А: «uAsm: строка N: текст»);
               печать — словом prints, номер строки — printu; кирпич
               fail.

МЕТОД targs ( -- addr )
  вход:        нет
  выход:       addr: слово — адрес строки «слишком много аргументов»
               (UTF-8 + 0)
  функция:     Данные: текст ошибки ёмкости буфера аргументов (SPEC/
               L4-SELFHOST.txt, раздел 5А: больше 256 аргументов DB/DW в
               одной строке); печать — fail.

МЕТОД fail ( a -- )
  вход:        a: слово — адрес текста ошибки (Z-строка)
  выход:       нет; не возвращается: строка выводится в stdout, затем
               программа
  выход:       завершается кодом 16
  функция:     Диагностика ошибки входа (SPEC/L4-SELFHOST.txt, раздел
               5А): печатает «uAsm: строка N: » (tuasm, номер строки ln,
               printu, двоеточие и пробел), текст ошибки (prints),
               перевод строки и завершает программу словом QUIT (HALT
               16); образ при ошибке не выводится.
  зависимости: tuasm, ln, printu, EMIT, space, prints, cr, QUIT

МЕТОД argpstep ( -- done )
  вход:        нет (клетки ai, argc — состояние печати; буфер
               аргументов)
  выход:       done: слово — 0: аргумент выведен; 1: аргументов больше
               нет
  функция:     Один шаг печати аргументов строки: пара ai лежит по
               адресу argbase + ai * 16 — адрес слова (LOAD64) и длина
               (LOAD64 с адреса пары + 8); перед аргументом — пробел;
               кирпич argprint.
  зависимости: ai, argc, argbase, LTU, not, MUL, ADD, LOAD64, space,
               printw

МЕТОД argprint ( -- )
  вход:        нет (клетка argc и буфер аргументов — аргументы строки)
  выход:       нет (аргументы выводятся в stdout через пробел)
  функция:     Печатает аргументы строки: пары буфера аргументов по
               порядку, перед каждым — пробел (space + printw); кирпич
               listline.
  зависимости: ai, argpstep

МЕТОД listline ( -- )
  вход:        нет (клетки ln, wa, wl, argc и буфер аргументов — строка)
  выход:       нет (строка листинга выводится в stdout)
  функция:     Промежуточное поведение подшага 2 (SPEC/L4-SELFHOST.txt,
               раздел 5А; заменяется разбором строки в запись в подшаге
               4): печатает строку листинга «N:слово[=код] аргументы» —
               номер строки (printu), двоеточие, первое слово (printw),
               код мнемоники после «=» (mnem, printu), аргументы через
               пробел (argprint), перевод строки; пустые строки и
               комментарии молчат (их отсеивает doline).
  зависимости: ln, printu, wa, wl, printw, mnem, argprint, cr, EMIT

МЕТОД doline ( s q -- )
  вход:        s: слово — адрес первого байта строки буфера
  вход:        q: слово — адрес за последним байтом строки (на LF либо
               be)
  выход:       нет (строка обрабатывается; вывод подшага 2 — listline)
  функция:     Обрабатывает одну строку (SPEC/L4-SELFHOST.txt, раздел
               5А, подшаг 2): снимает концевые CR (crstep), отрезает
               комментарий «;» вне кавычек (findsemi), снимает крайние
               пробелы и табуляции (rtrim, ltrim); пустая строка или
               комментарий — тишина; иначе splitword (первое слово и
               остаток), splitargs (аргументы парами) и listline. Подшаг
               4 заменит listline разбором строки в запись.
  зависимости: crstep, findsemi, rtrim, ltrim, LTU, not, splitword,,
               splitargs, listline

МЕТОД main ( -- )
  вход:        нет (вход инструмента — байты stdin, KEY)
  выход:       нет (выход подшага 2 — листинг строк в stdout, EMIT; код
  выход:       завершения 0 — успех, 16 — ошибка входа)
  функция:     Каркас ассемблера (SPEC/L4-SELFHOST.txt, раздел 5А):
               читает stdin целиком в буфер источника (readstep, конец —
               в be), ставит bp на начало буфера и ln = 1, проходит
               строки (linestep до конца) и завершается BYE; пустой вход
               — пустой вывод. Разбор в записи и сборка образа — подшаги
               4-6.
  зависимости: srcbase, readstep, be, bp, ln, linestep, BYE

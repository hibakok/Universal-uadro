КАРТОЧКИ ФАЙЛА src/l2/asmwords.ubrk

Ветвь: l2.uasm.assemble
Слой: L2
Методов: 16
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Ассемблер uAsm — строки и слова: use-включение главного файла
          src/l2/assemble.ubrk (SPEC/L4-SELFHOST.txt, раздел 5А, подшаг
          2). Деление буфера источника на строки со счётчиком
          (linestep), чистка строки (концевые CR, комментарий «;» вне
          кавычек, крайние пробелы), первое слово и остаток (splitword),
          слова аргументов в пары буфера аргументов (splitargs), поиск
          байта вне кавычек (findch — «;» и «=», подшаг 4).

МЕТОД isspace ( c -- ф )
  вход:        c: слово — байт 0..255
  выход:       ф: слово — 1: пробел (32) или табуляция (9); иначе 0
  функция:     Признак разделителя слов (SPEC/L2-UASM.txt, раздел 2);
               кирпич чистки строки и разбиения на слова.
  зависимости: EQ

МЕТОД cstep ( -- done )
  вход:        нет (клетки cp, qe, cq, cb — состояние скана)
  выход:       done: слово — 0: позиция cp движется; 1: стоп — cp за
               пределом
  выход:       либо на искомом байте cb вне кавычек
  функция:     Один шаг поиска байта cb вне литералов (SPEC/L2-UASM.txt,
               раздел 2, как find_outside_quotes эталона): вне кавычки
               «"» (34) и «'» (39) открывают литерал; внутри литерала
               «\» (92) пропускает два байта, парная кавычка закрывает;
               байт cb вне кавычек — стоп; незакрытая кавычка тянется до
               предела диапазона.
  зависимости: cp, qe, cq, cb, LTU, not, EQ

МЕТОД findch ( s e b -- s cut )
  вход:        s: слово — адрес первого байта диапазона
  вход:        e: слово — адрес за последним байтом диапазона
  вход:        b: слово — искомый байт 0..255
  выход:       s: слово — прежний адрес начала (передаётся дальше по
               цепочке)
  выход:       cut: слово — адрес первого b вне кавычек либо e (байта
               нет)
  функция:     Ищет первый байт b вне литералов в кавычках в [s, e)
               (SPEC/ L2-UASM.txt, раздел 2, как find_outside_quotes
               эталона): cstep сканирует диапазон со значением cb = b;
               перелёт escape за e выравнивается на e; кирпичи findsemi
               и разбора константы (asmline.ubrk, подшаг 4).
  зависимости: cb, cp, qe, cq, cstep, LTU, not

МЕТОД findsemi ( s e -- s cut )
  вход:        s: слово — адрес первого байта диапазона
  вход:        e: слово — адрес за последним байтом диапазона
  выход:       s: слово — прежний адрес начала (передаётся дальше по
               цепочке)
  выход:       cut: слово — адрес «;» вне кавычек либо e (комментария
               нет)
  функция:     Ищет начало комментария в [s, e) (SPEC/L2-UASM.txt,
               раздел 2): findch с искомым байтом «;» (59); перелёт
               escape за e выравнивается на e; кирпич doline главного
               файла.
  зависимости: findch

МЕТОД crstep ( s e -- s e done )
  вход:        s: слово — адрес первого байта строки
  вход:        e: слово — адрес за последним байтом строки
  выход:       s, e: слово — границы после шага (e уменьшается на
               концевой CR)
  выход:       done: слово — 0: концевой CR (13) снят, продолжить; 1:
               снимать
  выход:       нечего (не CR или строка пуста)
  функция:     Один шаг снятия концевых CR (SPEC/L4-SELFHOST.txt, раздел
               5А: концевой CR снимается — как rstrip("\r") split_lines
               эталона, все концевые CR подряд); кирпич doline.
  зависимости: LTU, not, EQ

МЕТОД rtrimstep ( s e -- s e done )
  вход:        s: слово — адрес первого байта
  вход:        e: слово — адрес за последним байтом
  выход:       s, e: слово — границы после шага (e уменьшается на
               пробел)
  выход:       done: слово — 0: концевой пробел/табуляция сняты; 1:
               снимать
  выход:       нечего
  функция:     Один шаг чистки конца строки от пробелов и табуляций
               (SPEC/L2-UASM.txt, раздел 2: крайние пробелы
               игнорируются); кирпич rtrim.
  зависимости: LTU, not, isspace

МЕТОД rtrim ( s e -- s e' )
  вход:        s: слово — адрес первого байта
  вход:        e: слово — адрес за последним байтом
  выход:       s, e': слово — конец без концевых пробелов и табуляций
  функция:     Снимает концевые пробелы и табуляции (цикл rtrimstep);
               кирпич doline.
  зависимости: rtrimstep

МЕТОД ltrimstep ( s e -- s' e done )
  вход:        s: слово — адрес первого байта
  вход:        e: слово — адрес за последним байтом
  выход:       s': слово — начало без начального пробела/табуляции
  выход:       e: слово — прежний конец
  выход:       done: слово — 0: начальный пробел снят; 1: снимать нечего
  функция:     Один шаг чистки начала строки (SPEC/L2-UASM.txt, раздел
               2); кирпич ltrim.
  зависимости: LTU, not, isspace

МЕТОД ltrim ( s e -- s' e )
  вход:        s: слово — адрес первого байта
  вход:        e: слово — адрес за последним байтом
  выход:       s': слово — начало без начальных пробелов и табуляций
  выход:       e: слово — прежний конец
  функция:     Снимает начальные пробелы и табуляции (цикл ltrimstep);
               также пропускает пробелы после первого слова (кирпичи
               splitword и argstep).
  зависимости: ltrimstep

МЕТОД lfstep ( -- done )
  вход:        нет (клетки cp, qe — состояние скана)
  выход:       done: слово — 0: cp движется; 1: cp — на LF (10) либо за
  выход:       пределом диапазона
  функция:     Один шаг поиска перевода строки LF — делителя строк
               буфера (SPEC/L4-SELFHOST.txt, раздел 5А); кирпич
               linestep.
  зависимости: cp, qe, LTU, not, EQ

МЕТОД spstep ( -- done )
  вход:        нет (клетки cp, qe — состояние скана)
  выход:       done: слово — 0: cp движется; 1: cp — на
               пробеле/табуляции либо
  выход:       за пределом диапазона
  функция:     Один шаг поиска разделителя слов (SPEC/L2-UASM.txt,
               раздел 2); кирпич findfirst.
  зависимости: cp, qe, LTU, not, isspace

МЕТОД findfirst ( s e -- w )
  вход:        s: слово — адрес первого байта
  вход:        e: слово — адрес за последним байтом
  выход:       w: слово — адрес первого пробела/табуляции в [s, e) либо
               e
  функция:     Конец первого слова диапазона: spstep сканирует [s, e);
               кирпичи splitword и argstep.
  зависимости: cp, qe, spstep

МЕТОД splitword ( s e -- )
  вход:        s: слово — адрес первого байта чистой строки
  вход:        e: слово — адрес за последним байтом чистой строки
  выход:       нет; клетки wa/wl — адрес и длина первого слова, ra/rl —
               адрес
  выход:       и длина остатка (пробелы после слова сняты)
  функция:     Делит чистую строку на первое слово и остаток
               (SPEC/L2-UASM.txt, раздел 2, как split_first эталона):
               конец слова — findfirst, остаток — ltrim от конца слова;
               слово без пробела занимает строку целиком, остаток пуст.
  зависимости: findfirst, ltrim, wa, wl, ra, rl, ROT, DUP, SWAP, SUB,
               NEG,, ADD, OVER, STORE64, LOAD64

МЕТОД argstep ( -- done )
  вход:        нет (клетки ap, ae, argc — состояние разбора остатка)
  выход:       done: слово — 0: слово-аргумент сохранено в пары; 1:
               аргументов
  выход:       больше нет
  функция:     Один шаг разбора остатка на слова-аргументы
               (SPEC/L2-UASM.txt, раздел 2, как split_words эталона;
               SPEC/L4-SELFHOST.txt, раздел 5А): пропускает пробелы
               (ltrim), слова нет — конец; пара «адрес, длина» (16
               байтов LE) пишется в буфер аргументов по адресу argbase +
               argc * 16, argc растёт, ap ставится на конец слова; 257-й
               аргумент строки — диагностика «слишком много аргументов»
               (fail, код 16).
  зависимости: ap, ae, argc, ltrim, findfirst, argbase, targs, fail,
               LTU,, not, OVER, SUB, MUL, ADD, ROT, SWAP, DUP, STORE64

МЕТОД splitargs ( -- )
  вход:        нет (клетки ra, rl — остаток строки после первого слова)
  выход:       нет; клетки argc и буфер аргументов — пары слов остатка
  функция:     Разбирает остаток строки на слова-аргументы (SPEC/
               L4-SELFHOST.txt, раздел 5А, подшаг 2): обнуляет argc,
               ставит ap на начало остатка, ae — за его конец, argstep
               до конца; пустой остаток — ноль пар.
  зависимости: ra, rl, ap, ae, argc, argstep

МЕТОД linestep ( -- done )
  вход:        нет (клетки bp, be, ln — состояние прохода по строкам)
  выход:       done: слово — 0: строка обработана, проход продолжается;
               1: строк
  выход:       больше нет (bp достиг be)
  функция:     Один шаг прохода по строкам буфера источника (SPEC/
               L4-SELFHOST.txt, раздел 5А, подшаг 2): lfstep ищет конец
               строки [bp, lq) — LF либо конец буфера; doline
               обрабатывает строку (сканеры doline затирают cp, поэтому
               конец хранится в lq); найденный LF — bp за ним и ln + 1;
               строка без LF (последняя) — bp = be. Проход
               переиспользуется проходами ассемблера (подшаги 5-6).
  зависимости: bp, be, ln, lq, cp, qe, lfstep, doline, LTU, not

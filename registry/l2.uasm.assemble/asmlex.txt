КАРТОЧКИ ФАЙЛА src/l2/asmlex.ubrk

Ветвь: l2.uasm.assemble
Слой: L2
Методов: 19
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Ассемблер uAsm — литералы и имена: use-включение главного
          файла src/l2/assemble.ubrk (SPEC/L4-SELFHOST.txt, раздел 5А,
          подшаг 3). Чистые лексические кирпичи без печати — собственное
          воплощение эталона tools/uasm_lex.py (SPEC/L2-UASM.txt,
          разделы 3-4): числовые формы (десятичная, шестнадцатеричная,
          двоичная, символьная) с контролем переполнения слова, минус и
          диапазон -2^63..2^64-1, имена [A-Za-z_][A-Za-z0-9_]* и скан
          строкового литерала DS/DZ (длина декодированных байтов).
          Значение разбора — в клетке lexv; вид исхода (kind): 1 — форма
          подошла, 2 — цифры верны, но значение вне диапазона, 0 — форма
          нарушена; скан строк печатает и хранит только длину.

МЕТОД hexdig ( c -- v 1 | 0 )
  вход:        c: слово — байт 0..255
  выход:       pair: v и флаг 1 — значение шестнадцатеричной цифры
               0..15;
  выход:       либо 0 без флага — байт не шестнадцатеричная цифра
  функция:     Таблица шестнадцатеричных цифр сравнениями
               (SPEC/L2-UASM.txt, раздел 4): '0'-'9' (48-57) — 0..9,
               'A'-'F' (65-70) — 10..15, 'a'-'f' (97-102) — 10..15;
               кирпич lexstep.
  зависимости: LTU, LEU, SUB, DUP, DROP, IF, EXIT, THEN

МЕТОД lexstep ( -- done )
  вход:        нет (клетки lexb, lp, le, lexv, lexo — состояние разбора)
  выход:       done: слово — 0: цифра учтена, разбор продолжается; 1:
               предел
  выход:       достигнут либо байт не цифра (вызывающий различает по lp
               < le)
  функция:     Один шаг накопления цифр числовой формы
               (SPEC/L2-UASM.txt, раздел 4): hexdig даёт значение v <
               lexb, иначе стоп (форма нарушена; не-цифра оставляет на
               стеке только свой ноль и байт c — после IF снимается
               ровно c); при включённом lexo цифра проверяется, но не
               копится — форма доразбирается до конца, чтобы отличить
               переполнение от мусора; шаг копит lexv = lexv * lexb + v,
               контроль переполнения — обратное деление: без обрыва по
               модулю 2^64 частное acc / lexb обязано вернуть lexv (acc
               = lexv * lexb + v, v < lexb); обрыв частного —
               переполнение слова, lexo = 1.
  зависимости: lexb, lp, le, lexv, lexo, LTU, not, LOAD8, hexdig, MUL,
               ADD,, UDIV, NEQ, EQ, STORE64, SWAP, DROP, DUP, IF, EXIT,
               THEN

МЕТОД parseuns ( a l base -- kind )
  вход:        a: слово — адрес первого байта цифр
  вход:        l: слово — число байтов цифр
  вход:        base: слово — основание системы: 10, 16 или 2
  выход:       kind: слово — 1: модуль разобран, lexv — значение
               0..2^64-1;
  выход:       2: все байты — цифры, но модуль превысил 2^64-1 (lexo);
  выход:       0: форма нарушена — не-цифра до конца слова
  функция:     Накапливает модуль числовой формы без знака (кирпичи
               decform, hexform, binform): ставит lexb/lp/le/lexv/lexo и
               гонит lexstep до стопа; переполнение доразбирает форму —
               чтобы различить «вне диапазона» (kind 2) и «плохой
               литерал» (kind 0), как parse_dec эталона и
               in_literal_range по его значению.
  зависимости: lexb, le, lp, lexv, lexo, lexstep, ADD, ROT, SWAP, OVER,
               DROP,, STORE64, LOAD64, EQ, IF, ELSE, THEN, EXIT

МЕТОД charform ( a l -- kind )
  вход:        a: слово — адрес первого байта слова
  вход:        l: слово — число байтов слова
  выход:       kind: слово — 1: символьная форма, lexv — код 0..255; 0:
               не форма
  функция:     Распознаёт символьную форму 'X' или '\e'
               (SPEC/L2-UASM.txt, раздел 4, parse_char эталона): три

  зависимости: escval, EQ, not, LOAD8, lexv, DUP, DROP, OVER, ADD, ROT,
               SWAP,, STORE64, IF, ELSE, THEN, EXIT

  вход:        a: слово — адрес первого байта слова без знака
  вход:        l: слово — число байтов слова без знака
  выход:       kind: слово — 1: lexv — модуль 0..2^64-1; 2: цифры верны,

  выход:       вне 2^64-1; 0: ни одна форма не подошла
  функция:     Пробует формы без знака по порядку эталона literal_value

МЕТОД numlit ( a l -- kind )
  вход:        a: слово — адрес первого байта слова-аргумента
  вход:        l: слово — число байтов слова-аргумента
  выход:       kind: слово — 1: числовой литерал в диапазоне, lexv —
               значение
  выход:       по модулю 2^64 (отрицательные обёрнуты); 2: цифры верны,
  выход:       значение вне -2^63..2^64-1; 0: не числовой литерал
  функция:     Полный числовой литерал (SPEC/L2-UASM.txt, раздел 4,
               parse_number и in_literal_range эталона): минус (45) без
               пробела перед формой берёт тело после знака; модуль без
               знака 0..2^64-1 всегда в диапазоне, с минусом — модуль не
               больше 2^63; отрицательное значение оборачивается по
               модулю 2^64 (NEG, SPEC/L0-UVM.txt, раздел 1); пустое
               слово и «-» без тела — не литерал.
  зависимости: numform, lexv, LOAD8, LOAD64, STORE64, EQ, LEU, NEG, ADD,
               SUB,, SWAP, DUP, OVER, IF, ELSE, THEN, EXIT, DROP

МЕТОД strstep ( -- done )
  вход:        нет (клетки sp, se, sl, sf — состояние скана)
  выход:       done: слово — 0: байт декодирован, скан продолжается; 1:
               скан
  выход:       окончен (успех либо ошибка — различает sf)
  функция:     Один шаг скана строкового литерала "..."
               (SPEC/L2-UASM.txt, раздел 4, parse_string эталона):
               закрывающая кавычка 34 обязана быть последним байтом —
               иначе sf; обратный слэш 92 требует валидный байт из
               streval — один декодированный байт; прочие байты (в том
               числе многобайтовый UTF-8) идут дословно, по одному
               декодированному байту каждый; конец диапазона до
               закрывающей кавычки и обрыв escape — sf.
  зависимости: sp, se, sl, sf, LTU, not, LOAD8, streval, EQ, ADD,
               STORE64,, LOAD64, DUP, DROP, IF, ELSE, THEN, EXIT

               первый байт, минимум два байта, дальше strstep до конца;

  зависимости: sp, se, sl, sf, strstep, LTU, not, LOAD8, EQ, ADD, ROT,

КАРТОЧКИ ФАЙЛА tools/uvm_table.py

Ветвь: t0.uvm.table
Слой: T0
Методов: 6
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Таблица опкодов UVM: код, мнемоника, обработчик, признак imm64
          40 записей — v0.1 + DEVRD/DEVWR v0.3 (SPEC/L0-UVM.txt, раздел
          5).

МЕТОД entry_by_code(code) -> tuple
  вход:        code: int — опкод 0..255
  выход:       entry: tuple — (код, мнемоника, обработчик, imm64) или
               None
  функция:     Находит запись опкода в таблице; неизвестный код — None.

МЕТОД entry_by_mnemonic(mnemonic) -> tuple
  вход:        mnemonic: str — мнемоника опкода (например, "PUSH")
  выход:       entry: tuple — (код, мнемоника, обработчик, imm64) или
               None
  функция:     Находит запись по мнемонике; неизвестная мнемоника —
               None. Кирпич ассемблера и дизассемблера (Этап 2).

МЕТОД mnemonic_of(code) -> str
  вход:        code: int — опкод 0..255
  выход:       name: str — мнемоника опкода или None для неизвестного
               кода
  функция:     Даёт мнемонику опкода; кирпич дизассемблера (Этап 2).
  зависимости: entry_by_code

МЕТОД handler_of(code) -> callable
  вход:        code: int — опкод 0..255
  выход:       handler: callable — обработчик handler(m, imm) или None
  функция:     Даёт обработчик опкода; кирпич ветвей t0.uvm.decode и
               t0.uvm.exec.
  зависимости: entry_by_code

МЕТОД has_imm(code) -> bool
  вход:        code: int — опкод 0..255
  выход:       flag: bool — True, если за опкодом следует поле imm64
  функция:     Показывает формат инструкции: 1 байт опкода либо 1 байт +
               8 байтов imm64; для неизвестного кода — False (сам код
               проверяет entry_by_code).
  зависимости: entry_by_code

МЕТОД code_of(mnemonic) -> int
  вход:        mnemonic: str — мнемоника опкода
  выход:       code: int — опкод 0..255 или None для неизвестной
               мнемоники
  функция:     Даёт код опкода по мнемонике; кирпич ассемблера (Этап 2).
  зависимости: entry_by_mnemonic

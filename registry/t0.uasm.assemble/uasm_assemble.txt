КАРТОЧКИ ФАЙЛА tools/uasm_assemble.py

Ветвь: t0.uasm.assemble
Слой: T0
Методов: 6
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Сборка текста uAsm в образ UVM двумя проходами: проход 1
          назначает записям адреса и заполняет таблицу символов, проход
          2 кодирует записи в байты (SPEC/L2-UASM.txt, раздел 7).

МЕТОД split_lines(text) -> list
  вход:        text: str — исходный текст uAsm
  выход:       lines: list — строки текста без концевых байтов CR
  функция:     Делит текст на строки по символу LF; концевой CR каждой
               строки снимается — текст с переводами CRLF собирается так
               же, как с LF (SPEC/L2-UASM.txt, раздел 2); текст без LF
               даёт одну строку, пустой текст — одну пустую строку.

МЕТОД wrap_error(line_no, text) -> str
  вход:        line_no: int — номер строки текста, начиная с 1
  вход:        text: str — текст ошибки
  выход:       msg: str — сообщение «uAsm: строка N: текст»
  функция:     Приписывает ошибке номер строки по разделу 7
               SPEC/L2-UASM.txt.

МЕТОД define_symbol(symbols, record, addr) -> str
  вход:        symbols: dict — таблица символов (метод добавляет имя)
  вход:        record: tuple — запись строки: ("label", имя) либо
  вход:        ("const", имя, значение); записи других видов не
               определяют
  вход:        ничего
  вход:        addr: int — адрес байта следующей записи — значение метки
  выход:       error: str — текст ошибки повторного определения либо
               None,
  выход:       если имя определено впервые
  функция:     Определяет символ прохода 1 (SPEC, разделы 3 и 7): метка
               — адресом следующей записи, константа — своим значением.
  зависимости: symbol_define

МЕТОД pass1(lines) -> tuple
  вход:        lines: list — строки текста uAsm
  выход:       triple: tuple — (записи, таблица символов, None) либо
  выход:       (None, None, текст ошибки «uAsm: строка N: ...»); записи
               —
  выход:       список пар (номер строки, запись) всех разобранных строк,
  выход:       без пустых строк и комментариев
  функция:     Проход 1 сборки (SPEC, раздел 7): разбирает строки в
               записи (parse_line), первая ошибка прекращает проход;
               определяет метки адресами и константы значениями
               (define_symbol); накапливает адрес по размерам записей
               (record_size) — метка получает адрес следующей записи,
               метка в конце текста — адрес конца образа; метки и
               константы сами байтов не дают.
  зависимости: parse_line, define_symbol, record_size, wrap_error

МЕТОД pass2(items, symbols) -> tuple
  вход:        items: list — пары (номер строки, запись) прохода 1
  вход:        symbols: dict — таблица символов прохода 1
  выход:       pair: tuple — (образ, None) либо (None, текст ошибки
  выход:       «uAsm: строка N: ...»)
  функция:     Проход 2 сборки (SPEC, раздел 7): кодирует записи в байты
               (encode_record) с подстановкой значений имён из таблицы
               символов — ссылки вперёд уже разрешены проходом 1; первая
               ошибка прекращает проход; образ — сцепление байтов
               записей в порядке следования.
  зависимости: encode_record, wrap_error

МЕТОД assemble(text) -> tuple
  вход:        text: str — исходный текст uAsm
  выход:       pair: tuple — (образ, None) либо (None, текст ошибки
  выход:       «uAsm: строка N: ...»); пустой текст — пустой образ
  функция:     Собирает текст uAsm в двоичный образ UVM двумя проходами
               (SPEC/L2-UASM.txt, раздел 7): split_lines -> pass1 ->
               pass2.
  зависимости: split_lines, pass1, pass2

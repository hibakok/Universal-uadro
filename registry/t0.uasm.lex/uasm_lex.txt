КАРТОЧКИ ФАЙЛА tools/uasm_lex.py

Ветвь: t0.uasm.lex
Слой: T0
Методов: 9
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Лексические кирпичи uAsm: числовые литералы (десятичные,
          шестнадцатеричные, двоичные, символьные, с минусом), имена и
          строковые литералы (SPEC/L2-UASM.txt, разделы 3-4).

МЕТОД parse_dec(text) -> int
  вход:        text: str — слово без пробелов
  выход:       value: int — значение или None, если это не десятичный
               литерал
  функция:     Распознаёт десятичный литерал: только ASCII-цифры 0-9,
               хотя бы одна (SPEC, раздел 4).

МЕТОД parse_hex(text) -> int
  вход:        text: str — слово без пробелов
  выход:       value: int — значение или None, если это не
               шестнадцатеричный
  выход:       литерал
  функция:     Распознаёт литерал с префиксом 0x (строчными) и цифрами
               0-9A-Fa-f; после префикса — хотя бы одна цифра (SPEC,
               раздел 4).

МЕТОД parse_bin(text) -> int
  вход:        text: str — слово без пробелов
  выход:       value: int — значение или None, если это не двоичный
               литерал
  функция:     Распознаёт литерал с префиксом 0b (строчными) и цифрами
               0/1; после префикса — хотя бы одна цифра (SPEC, раздел
               4).

МЕТОД parse_char(text) -> int
  вход:        text: str — слово без пробелов
  выход:       value: int — код символа или None, если это не символьный
  выход:       литерал
  функция:     Распознаёт символьный литерал 'X' (SPEC, раздел 4): один
               символ в одинарных кавычках — его код; либо escape '\n'
               '\r' '\t' '\\' '\'' '\0' — код из таблицы CHAR_ESCAPES.

МЕТОД literal_value(text) -> int
  вход:        text: str — слово без пробелов и без знака
  выход:       value: int — значение или None, если ни одна форма не
               подошла
  функция:     Пробует формы без знака: десятичную, шестнадцатеричную,
               двоичную, символьную (SPEC, раздел 4); кирпич
               parse_number.
  зависимости: parse_dec, parse_hex, parse_bin, parse_char

МЕТОД parse_number(text) -> int
  вход:        text: str — слово без пробелов, возможно с минусом
               впереди
  выход:       value: int — значение или None, если это не числовой
               литерал
  функция:     Полный числовой литерал (SPEC, раздел 4): необязательный
               минус без пробела после него перед десятичной,
               шестнадцатеричной, двоичной или символьной формой;
               диапазон проверяет отдельный кирпич in_literal_range.
  зависимости: literal_value

МЕТОД in_literal_range(value) -> bool
  вход:        value: int — значение числового литерала
  выход:       flag: bool — True, если значение внутри диапазона
               литералов
  функция:     Проверяет границы литералов -2^63 .. 2^64-1 (SPEC, раздел
               4); значение вне диапазона — ошибка сборки «литерал вне
               диапазона».

МЕТОД is_name(text) -> bool
  вход:        text: str — слово без пробелов
  выход:       flag: bool — True, если слово — допустимое имя
  функция:     Распознаёт имя [A-Za-z_][A-Za-z0-9_]* (SPEC, раздел 3):
               буква или подчёркивание, затем буквы, цифры,
               подчёркивания; только ASCII, регистр значим.

МЕТОД parse_string(text) -> bytes
  вход:        text: str — текст строкового литерала целиком, с
               кавычками
  выход:       data: bytes — байты UTF-8 без кавычек или None, если
               литерал
  выход:       неверен
  функция:     Распознаёт строковый литерал "..." (SPEC, раздел 4):
               escape \n \r \t \\ \" \0; незакрытая кавычка, посторонний
               символ после закрывающей кавычки и неизвестный escape
               дают None.

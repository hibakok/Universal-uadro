# Реестр методов

Файл генерируется автоматически инструментом `tools/registry_scan.py`.
Вручную не редактировать: карточки методов живут в исходниках (`@method`).

## [T0] tools/check_limits.py — ветвь `t0.infra.registry`

Проверка лимита строк: каждый файл репозитория не длиннее 500 строк.

### iter_repo_files(root) -> iterator

- **вход:** root: Path — корень репозитория
- **выход:** files: итератор Path — файлы без пропускаемых каталогов
- **функция:** Обходит дерево репозитория, исключая .git и __pycache__.

### count_lines(path) -> int

- **вход:** path: Path — путь к файлу
- **выход:** n: int — число строк (0 при ошибке чтения)
- **функция:** Считает строки текстового файла в кодировке UTF-8.

### main() -> int

- **вход:** нет
- **выход:** code: int — 0 если нарушений нет, иначе 1
- **функция:** Печатает файлы сверх лимита и возвращает код завершения.

## [T0] tools/registry_scan.py — ветвь `t0.infra.registry`

Генератор реестра методов: собирает карточки @method из исходников и пишет registry/METHODS.md. Режим --check только сверяет реестр.

### _strip_tag(line) -> tuple

- **вход:** line: str — строка исходного файла
- **выход:** pair: tuple — (ключ, значение) для строки "# @ключ значение", иначе (None, "")
- **функция:** Распознаёт строки-аннотации "# @ключ значение".

### parse_file_header(lines) -> dict

- **вход:** lines: list[str] — строки файла
- **выход:** header: dict — поля file, layer, branch, desc (список строк)
- **функция:** Читает шапку файла: непрерывный блок "# @..." в начале файла.

### parse_method_cards(lines) -> list

- **вход:** lines: list[str] — строки файла
- **выход:** cards: list[dict] — карточки с полями name, in, out, does, uses, depends
- **функция:** Собирает карточки: строка "@method" открывает карточку, последующие
- **функция:** строки "@in/@out/@does/@uses/@depends" наполняют её, любая другая
- **функция:** строка закрывает.

### collect_sources() -> list

- **вход:** нет
- **выход:** paths: list[Path] — отсортированные *.py из каталогов исходников
- **функция:** Обходит существующие каталоги SOURCE_DIRS и собирает .py-файлы.

### render_registry(entries) -> str

- **вход:** entries: list[dict] — элементы: path, header, cards
- **выход:** text: str — полный текст registry/METHODS.md
- **функция:** Формирует markdown: раздел на файл, внутри — карточки методов.

### scan_repository() -> str

- **вход:** нет
- **выход:** text: str — текст реестра для текущего состояния исходников
- **функция:** Обходит исходники, парсит шапки и карточки, рендерит реестр.

### main(argv) -> int

- **вход:** argv: list[str] — аргументы командной строки
- **выход:** code: int — 0 — успех; 1 — реестр устарел (только для --check)
- **функция:** Без --check записывает реестр; с --check сверяет без записи.

**Всего методов: 10**

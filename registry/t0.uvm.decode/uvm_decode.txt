КАРТОЧКИ ФАЙЛА tools/uvm_decode.py

Ветвь: t0.uvm.decode
Слой: T0
Методов: 2
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Декодер инструкции UVM v0.1 по адресу: опкод, поле imm64
          little-endian, адрес следующей инструкции (SPEC/L0-UVM.txt,
          раздел 4).

МЕТОД decode_at(m, addr) -> tuple
  вход:        m: Machine — состояние машины (не меняется)
  вход:        addr: int — адрес байта опкода в ОЗУ
  выход:       entry: tuple — запись таблицы (код, мнемоника,
               обработчик, imm64)
  выход:       imm: int — значение поля imm64 или 0, если поля нет
  выход:       next_addr: int — адрес байта, следующего за инструкцией
               целиком
  функция:     Читает инструкцию по адресу: опкод из ОЗУ, при наличии
               поля imm64 — восемь байтов little-endian за ним;
               неизвестный опкод — ловушка 6, выход за границы ОЗУ —
               ловушка 7; кирпич дизассемблера (Этап 2) и отладчика
               (Этап 11). Горячий путь интерпретатора: опкод и imm64
               читаются встроенными срезами, поле на границе ОЗУ —
               побайтово через load_byte (ловушка 7 на первом байте вне
               ОЗУ, как раньше).
  зависимости: load_byte, trap, BY_CODE

МЕТОД decode(m) -> tuple
  вход:        m: Machine — состояние машины; PC указывает на байт
               опкода
  выход:       handler: callable — обработчик handler(m, imm) из таблицы
               опкодов
  выход:       imm: int — значение поля imm64 или 0, если поля нет
  функция:     Декодирует инструкцию по PC и переводит PC на байт,
               следующий за инструкцией целиком (включая поле imm64) —
               контракт обработчиков ветви t0.uvm.exec; при ловушке PC
               остаётся прежним; ловушки — как у decode_at.
  зависимости: decode_at

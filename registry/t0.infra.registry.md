# Карточки ветви t0.infra.registry

Слой T0, методов: 38. Генерируется `tools/registry_scan.py`; вручную не редактировать.

## tools/check_limits.py

_Проверка лимита строк: каждый файл репозитория не длиннее 500 строк._

### iter_repo_files(root) -> iterator

- **вход:** root: Path — корень репозитория
- **выход:** files: итератор Path — файлы без пропускаемых каталогов
- **функция:** Обходит дерево репозитория, исключая .git и __pycache__.

### count_lines(path) -> int

- **вход:** path: Path — путь к файлу
- **выход:** n: int — число строк (0 при ошибке чтения)
- **функция:** Считает строки текстового файла в кодировке UTF-8.

### main() -> int

- **вход:** нет
- **выход:** code: int — 0 если нарушений нет, иначе 1
- **функция:** Печатает файлы сверх лимита и возвращает код завершения.

## tools/registry_scan.py

_Генератор реестра методов: индекс registry/METHODS.md и карточки ветвей registry/<ветвь>.md. Режим --check сверяет реестр без записи._

### _strip_tag(line) -> tuple

- **вход:** line: str — строка исходного файла
- **выход:** pair: tuple — (ключ, значение) для строки "# @ключ значение", иначе (None, "")
- **функция:** Распознаёт строки-аннотации "# @ключ значение".

### parse_file_header(lines) -> dict

- **вход:** lines: list[str] — строки файла
- **выход:** header: dict — поля file, layer, branch, desc (список строк)
- **функция:** Читает шапку файла: непрерывный блок "# @..." в начале файла.

### parse_method_cards(lines) -> list

- **вход:** lines: list[str] — строки файла
- **выход:** cards: list[dict] — карточки с полями name, in, out, does, uses, depends
- **функция:** Собирает карточки: строка "@method" открывает карточку, последующие
- **функция:** строки "@in/@out/@does/@uses/@depends" наполняют её, любая другая
- **функция:** строка закрывает.

### collect_sources() -> list

- **вход:** нет
- **выход:** paths: list[Path] — отсортированные *.py из каталогов исходников
- **функция:** Обходит существующие каталоги SOURCE_DIRS и собирает .py-файлы.

### read_entries() -> list

- **вход:** нет
- **выход:** entries: list[dict] — элементы: path, header, cards
- **функция:** Читает все исходники и разбирает шапки и карточки.
- **зависимости:** collect_sources, parse_file_header, parse_method_cards

### branch_of(entry) -> str

- **вход:** entry: dict — элемент реестра (path, header, cards)
- **выход:** branch: str — имя ветви или no-branch, если в шапке нет ветви
- **функция:** Достаёт имя ветви из шапки файла.

### group_by_branch(entries) -> dict

- **вход:** entries: list[dict] — элементы реестра
- **выход:** groups: dict — ветвь -> список элементов в порядке обхода
- **функция:** Группирует файлы по ветвям.
- **зависимости:** branch_of

### sort_branches(groups) -> list

- **вход:** groups: dict — ветвь -> список элементов
- **выход:** names: list[str] — имена ветвей в стабильном порядке (слой, имя)
- **функция:** Даёт стабильный порядок ветвей в реестре.

### rel_path(entry) -> str

- **вход:** entry: dict — элемент реестра (path, header, cards)
- **выход:** rel: str — путь файла относительно корня репозитория
- **функция:** Преобразует путь в POSIX-вид для реестра.

### render_cards(entry) -> list

- **вход:** entry: dict — элемент реестра (path, header, cards)
- **выход:** lines: list[str] — markdown-строки: раздел файла с карточками методов
- **функция:** Рендерит заголовок файла и карточки его методов.

### branch_file_name(branch) -> str

- **вход:** branch: str — имя ветви
- **выход:** name: str — имя файла карточек ветви
- **функция:** Преобразует имя ветви в имя файла реестра (ветвь.md).

### render_branch_file(branch, entries) -> str

- **вход:** branch: str — имя ветви
- **вход:** entries: list[dict] — файлы ветви
- **выход:** text: str — текст файла registry/<ветвь>.md
- **функция:** Собирает карточки всех файлов ветви в один файл реестра.
- **зависимости:** render_cards

### render_index(groups) -> str

- **вход:** groups: dict — ветвь -> список элементов
- **выход:** text: str — текст индекса registry/METHODS.md
- **функция:** Формирует компактный индекс: ветви, их файлы, число методов.
- **зависимости:** sort_branches, rel_path, branch_file_name

### render_all(entries) -> dict

- **вход:** entries: list[dict] — элементы реестра
- **выход:** files: dict — имя файла -> текст (индекс + карточки ветвей)
- **функция:** Рендерит весь реестр целиком.
- **зависимости:** group_by_branch, render_index, render_branch_file, branch_file_name

### scan_repository() -> dict

- **вход:** нет
- **выход:** files: dict — имя файла -> текст реестра для текущих исходников
- **функция:** Обходит исходники и рендерит все файлы реестра.
- **зависимости:** read_entries, render_all

### check_registry(files) -> list

- **вход:** files: dict — имя файла -> ожидаемый текст
- **выход:** problems: list[str] — расхождения (пустой список = реестр актуален)
- **функция:** Сверяет ожидаемый реестр с файлами на диске, включая лишние файлы.

### write_registry(files) -> None

- **вход:** files: dict — имя файла -> текст
- **выход:** нет; файлы registry/ перезаписываются, лишние удаляются
- **функция:** Записывает реестр на диск.

### main(argv) -> int

- **вход:** argv: list[str] — аргументы командной строки
- **выход:** code: int — 0 — успех; 1 — реестр устарел (только для --check)
- **функция:** Без --check записывает реестр; с --check сверяет без записи.
- **зависимости:** scan_repository, check_registry, write_registry

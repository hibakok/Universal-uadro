КАРТОЧКИ ФАЙЛА tools/uasm_symbols.py

Ветвь: t0.uasm.symbols
Слой: T0
Методов: 3
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Таблица символов uAsm: имя -> значение; единое пространство
          имён для меток и констант; повторное определение имени —
          ошибка (SPEC/L2-UASM.txt, разделы 3 и 7).

МЕТОД symbols_new() -> dict
  вход:        нет
  выход:       table: dict — пустая таблица символов
  функция:     Создаёт новую пустую таблицу символов.

МЕТОД symbol_define(table, name, value) -> str
  вход:        table: dict — таблица символов (метод добавляет имя)
  вход:        name: str — имя символа
  вход:        value: int — значение символа (адрес или число)
  выход:       error: str — текст ошибки «повторное определение имени X»
  выход:       либо None, если имя определено впервые
  функция:     Определяет символ «имя -> значение» (SPEC, раздел 3);
               повторное определение — ошибка, прежнее значение
               сохраняется.

МЕТОД symbol_get(table, name) -> int
  вход:        table: dict — таблица символов
  вход:        name: str — имя символа
  выход:       value: int — значение символа или None, если имя не
               определено
  функция:     Выбирает значение символа по имени для подстановки в
               проход 2 (SPEC, разделы 3 и 7).

КАРТОЧКИ ФАЙЛА tools/uvm_run.py

Ветвь: t0.uvm.run
Слой: T0
Методов: 2
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Цикл запуска UVM v0.1: шаги step до UvmHalt или UvmTrap,
          приведение к коду завершения; кирпич run_image запускает
          готовый образ (SPEC/L0-UVM.txt, Этап 1).

МЕТОД run(m) -> int
  вход:        m: Machine — состояние машины; образ загружен, PC
               указывает
  вход:        на первую инструкцию
  выход:       code: int — код завершения: imm инструкции HALT по модулю
               256
  выход:       или код ловушки 1-8 (SPEC, раздел 3)
  функция:     Исполняет инструкции циклом step до остановки: UvmHalt и
               UvmTrap прекращают цикл, их поле code возвращается как
               код завершения; машина после остановки не сбрасывается
               (стеки, ОЗУ и PC доступны вызывающему).
  зависимости: step

МЕТОД run_image(image, ram_size, ds_size, rs_size) -> tuple
  вход:        image: bytes — образ программы
  вход:        ram_size: int — размер ОЗУ в байтах (по умолчанию 1 МиБ)
  вход:        ds_size: int — ёмкость стека данных в словах (по
               умолчанию 1024)
  вход:        rs_size: int — ёмкость стека возвратов в словах (по
               умолчанию 256)
  выход:       m: Machine — остановленная машина; её состояние доступно
  выход:       code: int — код завершения запуска
  функция:     Полный запуск образа (SPEC, раздел 2): свежая машина
               заданных размеров, загрузка образа с адреса 0, цикл run;
               кирпич ветви t0.uvm.cli и интеграционных программ Этапа
               1.
  зависимости: Machine, load_image, run

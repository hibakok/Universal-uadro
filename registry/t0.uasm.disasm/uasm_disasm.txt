КАРТОЧКИ ФАЙЛА tools/uasm_disasm.py

Ветвь: t0.uasm.disasm
Слой: T0
Методов: 6
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Дизассемблер образа UVM: линейное чтение с адреса 0, по одной
          инструкции на строку, хвост данных — директивами DB до восьми
          аргументов на строку (SPEC/L2-UASM.txt, раздел 8).

МЕТОД imm64_at(image, pos) -> int
  вход:        image: bytes — двоичный образ UVM
  вход:        pos: int — адрес первого байта поля imm64
  выход:       value: int — слово 0..2^64-1 little-endian либо None,
               если поле
  выход:       не помещается в образ
  функция:     Читает восемь байтов little-endian с адреса pos; кирпич,
               обратный word_le ветви t0.uasm.encode.

МЕТОД instr_line(mnemonic, value) -> str
  вход:        mnemonic: str — мнемоника опкода
  вход:        value: int — значение поля imm64 либо None, если поля нет
  выход:       line: str — «МНЕМОНИКА» или «МНЕМОНИКА значение»
  функция:     Печатает инструкцию одной строкой (SPEC, раздел 8):
               значение — десятичный литерал слова 0..2^64-1; имена не
               восстанавливаются.

МЕТОД decode_step(image, pos) -> tuple
  вход:        image: bytes — двоичный образ UVM
  вход:        pos: int — адрес байта опкода
  выход:       pair: tuple — (строка инструкции, адрес следующей) либо
  выход:       (None, pos) — сигнал останова декодирования
  функция:     Декодирует одну инструкцию с адреса pos (SPEC, раздел 8):
               неизвестный опкод или поле imm64, не помещающееся в
               образ, останавливают декодирование — с этого байта хвост
               печатается директивами DB.
  зависимости: mnemonic_of, has_imm, imm64_at, instr_line

МЕТОД db_lines(data) -> list
  вход:        data: bytes — хвост образа с байта останова декодирования
  выход:       lines: list — строки «DB b1 [b2 ...]» до восьми
               аргументов
  выход:       на строку; пустой хвост — пустой список
  функция:     Печатает данные директивами DB (SPEC, раздел 8): байты —
               десятичные литералы 0..255.

МЕТОД join_lines(lines) -> str
  вход:        lines: list — строки текста без переводов
  выход:       text: str — строки, разделённые LF; непустой текст
               оканчивается
  выход:       переводом строки, пустой список — пустой текст
  функция:     Собирает строки в текстовый файл uAsm; кирпич ветвей
               t0.uasm.disasm и t0.uasm.cli.

МЕТОД disasm(image) -> str
  вход:        image: bytes — двоичный образ UVM
  выход:       text: str — текст uAsm: по одной инструкции на строку,
               хвост
  выход:       данных — директивы DB; пустой образ — пустой текст
  функция:     Дизассемблирует образ линейно с адреса 0 (SPEC, раздел
               8): decode_step до останова декодирования, затем хвост
               директивами db_lines; раунд-трип assemble(disasm(B)) == B
               — критерий готовности Этапа 2 (ветвь
               t0.uasm.integration).
  зависимости: decode_step, db_lines, join_lines

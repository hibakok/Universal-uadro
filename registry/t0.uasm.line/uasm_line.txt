КАРТОЧКИ ФАЙЛА tools/uasm_line.py

Ветвь: t0.uasm.line
Слой: T0
Методов: 12
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Разбор одной строки uAsm в запись: метка, константа, директива
          данных, инструкция, пустая строка или комментарий; порядок
          разбора — SPEC/L2-UASM.txt, раздел 7.

МЕТОД find_outside_quotes(text, ch) -> int
  вход:        text: str — текст строки
  вход:        ch: str — искомый символ (один)
  выход:       index: int — позиция первого ch вне кавычек либо -1
  функция:     Ищет первое вхождение символа вне литералов в кавычках:
               символы внутри "..." и '...' не считаются, escape-кавычка
               не закрывает литерал; незакрытая кавычка тянется до конца
               строки (SPEC, раздел 2).

МЕТОД strip_comment(line) -> str
  вход:        line: str — исходная строка текста
  выход:       text: str — строка до комментария (крайние пробелы
               остаются)
  функция:     Удаляет комментарий: от «;» вне кавычек до конца строки
               (SPEC, раздел 2); «;» внутри "..." и '...' не начинается.
  зависимости: find_outside_quotes

МЕТОД clean_line(line) -> str
  вход:        line: str — исходная строка текста
  выход:       text: str — строка без комментария и крайних
               пробелов/табуляций
  функция:     Готовит строку к разбору (SPEC, раздел 2): комментарий
               «;» вне кавычек и пробелы с табуляциями по краям
               удаляются; пустой результат — пустая строка или
               строка-комментарий.
  зависимости: strip_comment

МЕТОД find_eq(text) -> int
  вход:        text: str — подготовленная строка
  выход:       index: int — позиция первого «=» вне кавычек либо -1
  функция:     Ищет знак «=» константы вне литералов в кавычках (SPEC,
               раздел 7, шаг 3 порядка разбора).
  зависимости: find_outside_quotes

МЕТОД split_first(text) -> tuple
  вход:        text: str — непустая строка без пробелов в начале
  выход:       pair: tuple — (первое слово, остаток без пробелов в
               начале)
  функция:     Отделяет первое слово (до пробела или табуляции) от
               остатка строки; пробелы внутри остатка значимы (SPEC,
               раздел 2).

МЕТОД split_words(text) -> list
  вход:        text: str — остаток строки после первого слова
  выход:       words: list — слова, разделённые пробелами и табуляциями
  функция:     Разбивает текст на слова по последовательностям пробелов
               и табуляций (SPEC, раздел 2); пустой текст даёт пустой
               список.

МЕТОД parse_label(word, rest) -> tuple
  вход:        word: str — первое слово строки, оканчивающееся на «:»
  вход:        rest: str — остаток строки после первого слова
  выход:       record: tuple — ("label", имя) либо ("error", "плохое
               имя")
  функция:     Разбирает метку «имя:» (SPEC, разделы 3 и 7): вся строка
               целиком, имя — по разделу 3; плохое имя или лишние слова
               после метки — «плохое имя».
  зависимости: is_name

МЕТОД bad_literal(text) -> str
  вход:        text: str — текст, оказавшийся не числовым литералом
  выход:       msg: str — текст ошибки «плохой литерал X»; без X, если
               текст
  выход:       пуст («плохой литерал»)
  функция:     Строит сообщение об ошибке по разделу 7 SPEC: X — слово
               или остаток строки из исходного текста.

МЕТОД parse_const(text, eq) -> tuple
  вход:        text: str — подготовленная строка со знаком «=» вне
               кавычек
  вход:        eq: int — позиция знака «=»
  выход:       record: tuple — ("const", имя, значение) либо ("error",
               текст):
  выход:       «плохое имя», «плохой литерал X», «литерал вне диапазона»
  функция:     Разбирает константу «имя = числовой литерал» (SPEC,
               раздел 3): имя — по разделу 3, значение — литерал раздела
               4 в диапазоне -2^63..2^64-1; константа не может ссылаться
               на имя.
  зависимости: is_name, parse_number, in_literal_range, bad_literal

МЕТОД parse_instr(mnemonic, imm64, rest) -> tuple
  вход:        mnemonic: str — мнемоника из таблицы опкодов
  вход:        imm64: bool — признак поля imm64 у опкода
  вход:        rest: str — остаток строки после мнемоники
  выход:       record: tuple — ("instr", мнемоника, операнд) либо
               ("error",
  выход:       «нет операнда у X» или «лишний операнд у X»)
  функция:     Разбирает инструкцию (SPEC, раздел 5): у опкода с полем
               imm64 операнд обязателен (остаётся текстом — значение
               подставит проход 2), у остальных операнд запрещён.

МЕТОД parse_data(directive, rest) -> tuple
  вход:        directive: str — DB, DW, DS или DZ
  вход:        rest: str — остаток строки после директивы
  выход:       record: tuple — ("data", директива, данные) либо
               ("error",
  выход:       «пустая директива X» или «плохой строковый литерал»)
  функция:     Разбирает директиву данных (SPEC, раздел 6): DB/DW —
               слова- аргументы (тексты, значения подставит проход 2);
               DS/DZ — ровно один строковый литерал в байтах UTF-8, DZ
               добавляет байт 0x00.
  зависимости: split_words, parse_string

МЕТОД parse_line(line) -> tuple
  вход:        line: str — исходная строка текста uAsm
  выход:       record: tuple — запись строки либо None (пустая строка
               или
  выход:       комментарий); виды записей перечислены в описании модуля
  функция:     Разбирает одну строку по порядку раздела 7
               SPEC/L2-UASM.txt: метка «имя:» -> инструкция или
               директива данных -> константа «=» -> иначе «неизвестная
               мнемоника X»; роль слова определяет позиция, поэтому имя
               метки может совпасть с мнемоникой, а константа с именем
               мнемоники невозможна.
  зависимости: clean_line, split_first, parse_label, parse_instr,
               parse_data, parse_const, find_eq, entry_by_mnemonic

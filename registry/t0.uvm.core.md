# Карточки ветви t0.uvm.core

Слой T0, методов: 42. Генерируется `tools/registry_scan.py`; вручную не редактировать.

## tools/uvm_core.py

_Ядро UVM: состояние машины, ловушки, ОЗУ и стеки DS/RS (SPEC/L0-UVM.md, Этап 1)._

### to_word(x) -> int

- **вход:** x: int — целое, возможно вне диапазона 64-битных слов
- **выход:** w: int — значение по модулю 2^64
- **функция:** Оборачивает целое в 64-битное слово: переполнения оборачиваются
- **функция:** (SPEC, раздел 1).

### to_byte(x) -> int

- **вход:** x: int — целое, возможно вне 0..255
- **выход:** b: int — младший байт 0..255
- **функция:** Оставляет младшие 8 бит значения.

### UvmTrap(code)

- **вход:** code: int — код завершения-ловушки 1..8 (SPEC, раздел 3)
- **выход:** exception — ловушка с полем code
- **функция:** Ловушка немедленно завершает исполнение с указанным кодом;
- **функция:** поднимается как исключение, ловит его цикл t0.uvm.run.

### trap(code) -> None

- **вход:** code: int — код ловушки
- **выход:** нет — всегда поднимает UvmTrap
- **функция:** Поднимает ловушку с кодом; исполнение немедленно завершается.
- **зависимости:** UvmTrap

### Machine(ram_size, ds_size, rs_size)

- **вход:** ram_size: int — размер ОЗУ в байтах (по умолчанию 1 МиБ)
- **вход:** ds_size: int — ёмкость стека данных в словах (по умолчанию 1024)
- **вход:** rs_size: int — ёмкость стека возвратов в словах (по умолчанию 256)
- **выход:** m: Machine — состояние UVM
- **функция:** Свежее состояние: ОЗУ из нулей, PC = 0, стеки DS и RS пусты
- **функция:** (SPEC, разделы 1-2).

### in_ram(m, addr) -> bool

- **вход:** m: Machine — состояние машины
- **вход:** addr: int — адрес байта
- **выход:** ok: bool — True, если адрес внутри ОЗУ
- **функция:** Проверяет принадлежность адреса ОЗУ: 0 <= addr < размер ОЗУ.

### load_byte(m, addr) -> int

- **вход:** m: Machine — состояние машины
- **вход:** addr: int — адрес байта
- **выход:** b: int — байт 0..255
- **функция:** Читает байт ОЗУ; адрес вне ОЗУ — ловушка 7.
- **зависимости:** in_ram, trap

### store_byte(m, addr, val) -> None

- **вход:** m: Machine — состояние машины
- **вход:** addr: int — адрес байта
- **вход:** val: int — значение; записывается его младший байт
- **выход:** нет
- **функция:** Пишет младший байт val в ОЗУ; адрес вне ОЗУ — ловушка 7.
- **зависимости:** in_ram, trap, to_byte

### load_word(m, addr) -> int

- **вход:** m: Machine — состояние машины
- **вход:** addr: int — адрес младшего байта слова
- **выход:** w: int — 64-битное слово
- **функция:** Собирает слово из 8 байтов ОЗУ в порядке little-endian, без
- **функция:** требования выравнивания (SPEC, раздел 1).
- **зависимости:** load_byte

### store_word(m, addr, val) -> None

- **вход:** m: Machine — состояние машины
- **вход:** addr: int — адрес младшего байта слова
- **вход:** val: int — слово; биты старше 64 игнорируются
- **выход:** нет
- **функция:** Раскладывает слово в 8 байтов ОЗУ в порядке little-endian,
- **функция:** без требования выравнивания.
- **зависимости:** store_byte

### load_image(m, image) -> None

- **вход:** m: Machine — состояние машины
- **вход:** image: bytes — образ программы
- **выход:** нет
- **функция:** Копирует образ в ОЗУ с адреса 0 и сбрасывает состояние запуска:
- **функция:** PC = 0, DS и RS пусты (SPEC, раздел 2); образ больше ОЗУ —
- **функция:** ловушка 7.
- **зависимости:** trap

### ds_push(m, w) -> None

- **вход:** m: Machine — состояние машины
- **вход:** w: int — слово; оборачивается по модулю 2^64
- **выход:** нет
- **функция:** Кладёт слово на стек данных; переполнение ёмкости — ловушка 3.
- **зависимости:** to_word, trap

### ds_pop(m) -> int

- **вход:** m: Machine — состояние машины
- **выход:** w: int — снятое слово
- **функция:** Снимает вершину стека данных; пустой стек — ловушка 2.
- **зависимости:** trap

### ds_pick(m, depth) -> int

- **вход:** m: Machine — состояние машины
- **вход:** depth: int — глубина элемента (0 — вершина)
- **выход:** w: int — копия элемента, стек не меняется
- **функция:** Копия элемента глубины depth; глубина вне стека — ловушка 2.
- **функция:** Кирпич инструкции PICK: depth 0 = DUP, depth 1 = OVER.
- **зависимости:** trap

### rs_push(m, w) -> None

- **вход:** m: Machine — состояние машины
- **вход:** w: int — слово; оборачивается по модулю 2^64
- **выход:** нет
- **функция:** Кладёт слово на стек возвратов; переполнение ёмкости — ловушка 5.
- **зависимости:** to_word, trap

### rs_pop(m) -> int

- **вход:** m: Machine — состояние машины
- **выход:** w: int — снятое слово
- **функция:** Снимает вершину стека возвратов; пустой стек — ловушка 4.
- **зависимости:** trap

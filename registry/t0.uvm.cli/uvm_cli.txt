КАРТОЧКИ ФАЙЛА tools/uvm_cli.py

Ветвь: t0.uvm.cli
Слой: T0
Методов: 5
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Запуск образа UVM из файла: разбор аргументов, чтение образа,
          исполнение run_image, код завершения UVM — в код выхода
          процесса (SPEC/L0-UVM.txt, Этап 1).

МЕТОД usage_text() -> str
  вход:        нет
  выход:       text: str — строка использования команды
  функция:     Даёт текст подсказки, которую main печатает в stderr при
               ошибке аргументов.

МЕТОД parse_size(text) -> int
  вход:        text: str — аргумент-размер из командной строки
  выход:       n: int — размер 1..2^31-1 или None
  функция:     Разбирает размер машины: только цифры, без знака; пустая
               строка, не-цифры, ноль и значения выше потолка дают None.

МЕТОД parse_args(argv) -> tuple
  вход:        argv: list — аргументы командной строки без имени
               программы
  выход:       parsed: tuple — (путь к образу, ram, ds, rs) или None
  функция:     Разбирает аргументы: первый аргумент — путь к файлу
               образа (обязателен), флаги --ram/--ds/--rs задают размеры
               ОЗУ и стеков (по умолчанию — из ядра t0.uvm.core);
               повторный флаг берёт последнее значение; неизвестный
               флаг, флаг без значения или плохой размер дают None.
  зависимости: parse_size

МЕТОД read_image(path) -> bytes
  вход:        path: str — путь к файлу образа
  выход:       image: bytes — байты образа или None, если файл не
               читается
  функция:     Читает файл образа целиком; отсутствие файла, каталог и
               другие ошибки доступа дают None (сообщение печатает
               main).

МЕТОД main(argv) -> int
  вход:        argv: list — аргументы командной строки без имени
               программы
  выход:       code: int — код выхода процесса: код UVM 0..255 либо 2
  функция:     Полный запуск из командной строки: parse_args,
               read_image, run_image; код завершения UVM (HALT или
               ловушка) становится кодом выхода, ловушка 7 загрузки
               (образ больше ОЗУ) — тоже; ошибки аргументов и файла
               печатаются в stderr с кодом 2.
  использует:  sys.stderr — стандартный вывод ошибок хоста
  зависимости: usage_text, parse_args, read_image, run_image

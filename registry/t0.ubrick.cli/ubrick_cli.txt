КАРТОЧКИ ФАЙЛА tools/ubrick_cli.py

Ветвь: t0.ubrick.cli
Слой: T0
Методов: 9
Генерируется tools/registry_scan.py; вручную не редактировать.
Описание: Командный режим uBrick: compile — чтение исходника, разбор,
          сборка образа UVM и запись результата; --asm сохраняет
          промежуточный текст uAsm (SPEC/L3-UBRICK.txt, раздел 9).

МЕТОД usage_text() -> str
  вход:        нет
  выход:       text: str — строка подсказки команды
  функция:     Даёт текст формы запуска, который main печатает в stderr
               при ошибке аргументов (SPEC/L3-UBRICK.txt, раздел 9).

МЕТОД parse_compile_args(rest) -> tuple
  вход:        rest: list — аргументы после слова compile
  выход:       parsed: tuple — ("compile", источник, образ, текст либо
               None)
  выход:       либо None
  функция:     Режим compile: ровно два пути — исходник и образ — и,
               возможно, флаг --asm с путём текста uAsm; иное число
               аргументов, флаг без значения и другие флаги дают None.

МЕТОД parse_args(argv) -> tuple
  вход:        argv: list — аргументы командной строки без имени
               программы
  выход:       parsed: tuple — ("compile", источник, образ, текст либо
               None)
  выход:       либо None
  функция:     Разбирает аргументы: первое слово — режим compile
               (единственный режим ветви), дальше аргументы режима;
               пустые аргументы и неизвестный режим — None.
  зависимости: parse_compile_args

МЕТОД read_text(path) -> str
  вход:        path: str — путь к файлу исходника uBrick
  выход:       text: str — текст файла либо None
  функция:     Читает исходник целиком в кодировке UTF-8; отсутствие
               файла, каталог и плохая кодировка дают None (сообщение
               печатает вызывающий режим).

МЕТОД write_bytes(path, data) -> str
  вход:        path: str — путь к файлу образа
  вход:        data: bytes — байты образа
  выход:       error: str — текст ошибки записи либо None при успехе
  функция:     Пишет байты в файл; ошибки доступа дают текст ошибки для
               stderr.

МЕТОД write_text(path, text) -> str
  вход:        path: str — путь к файлу текста
  вход:        text: str — текст uAsm
  выход:       error: str — текст ошибки записи либо None при успехе
  функция:     Пишет текст в файл в кодировке UTF-8; ошибки доступа дают
               текст ошибки для stderr.

МЕТОД write_asm_text(records, path) -> int
  вход:        records: tuple — записи разбора parse_ubrk
  вход:        path: str — путь к файлу текста uAsm
  выход:       code: int — 0 — текст записан; 2 — ошибка записи
  функция:     Сохраняет промежуточный текст uAsm (build_text) в файл
               флага --asm; ошибка записи — код 2 и сообщение в stderr.
  использует:  sys.stderr — стандартный вывод ошибок хоста
  зависимости: build_text, write_text

МЕТОД run_compile(parsed) -> int
  вход:        parsed: tuple — ("compile", источник, образ, текст либо
               None)
  вход:        из parse_args
  выход:       code: int — 0 — образ собран и записан; 2 — ошибка
  функция:     Режим compile: читает исходник (read_text), разбирает
               (parse_ubrk), собирает образ (build_ubrk) и пишет его
               (write_bytes); с флагом --asm дополнительно сохраняет
               промежуточный текст uAsm (write_asm_text); ошибка разбора
               или сборки печатается в stderr как есть («uBrick: строка
               N: текст» / «uAsm: строка N: текст»), ошибки файлов —
               своим сообщением; код ошибки — 2 (SPEC, раздел 9).
  использует:  sys.stderr — стандартный вывод ошибок хоста
  зависимости: read_text, parse_ubrk, build_ubrk, write_bytes,
               write_asm_text

МЕТОД main(argv) -> int
  вход:        argv: list — аргументы командной строки без имени
               программы
  выход:       code: int — 0 — успех; 2 — ошибка аргументов или режима
  функция:     Полный запуск команды: parse_args, затем режим compile
               (run_compile); ошибка аргументов печатает подсказку
               использования в stderr.
  использует:  sys.stderr — стандартный вывод ошибок хоста
  зависимости: usage_text, parse_args, run_compile

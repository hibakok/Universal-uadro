UNIVERSAL UADRO
===============

Инфраструктура «всё из кирпичиков»: собственный язык программирования
uadro, растущий с двоичного кода вверх, виртуальный процессор (UVM)
с ОЗУ и всё, что на нём будет построено.

ЧТО ЗДЕСЬ

- Универсальный бустрап: опкоды -> ассемблер (uAsm) -> кирпичный язык
  (uBrick) -> язык высокого уровня (uLang).
- Виртуальная машина UVM со своей спецификацией, не привязанной
  к существующим архитектурам.
- Самоописание: любой агент (ИИ или человек) может войти в проект
  и продолжить его, не читая репозиторий целиком.

КАРТА ВХОДА (читать по порядку)

1. CHARTER.txt — конституция проекта: неизменные правила.
2. ROADMAP.txt — этапы, критерии готовности, текущий статус.
3. DOC/ARCHITECTURE.txt — слои и ветви кода.
4. DOC/CONVENTIONS.txt — формат карточек методов и соглашения.
5. DOC/CONTINUE.txt — протокол продолжения работы (для ИИ и людей).
6. SPEC/ — спецификации слоёв; registry/ — реестр методов: индекс
   METHODS.txt и карточки по исходным файлам
   registry/<ветвь>/<файл>.txt.

ПРАВИЛА (кратко)

- Один метод — одна простая функция; сложное собирается из простых.
- Любой файл не длиннее 500 строк (проверяет CI).
- Каждый метод описан карточкой @method (вход / выход / функция).
- Сторонние библиотеки запрещены.
- Каждая правка оставляет репозиторий работоспособным, CI — зелёным.
- Файлы .md запрещены: вся документация — только .txt (UTF-8),
  простым текстом без разметки.

СТАТУС

Единственный источник статуса — ROADMAP.txt (раздел «Где мы сейчас»).

ЗАПУСК ПРОВЕРОК

    python tools/check_limits.py
    python -m unittest discover -s tests -t . -v
    python tools/registry_scan.py --check

Проверки автоматически выполняются в GitHub Actions при каждом коммите.
Реестр методов (каталог registry/) CI обновляет сам: вручную его
не редактируют и не вставляют.

ARCHITECTURE — СЛОИ И ВЕТВИ
===========================

СЛОИ (снизу вверх)

- Спецификации, SPEC/ — точные текстовые спецификации слоёв. Статус:
  есть.
- Бустрап-инструменты, T0 — Python-инструменты, временные «леса».
  Статус: есть.
- Двоичный слой, L1 — опкоды UVM, двоичные образы. Статус: есть
  (UVM v0.1: спецификация + эталон t0.uvm.*, Этап 1).
- Ассемблер, L2 — uAsm: мнемоники <-> биты. Статус: есть (uAsm
  v0.1, Этап 2 закрыт; исходники программ — src/*.uasm).
- Кирпичный язык, L3 — uBrick: слова-кирпичи. Статус: спецификация
  v0.1 принята (SPEC/L3-UBRICK.txt); реализация — Этап 3.
- Язык высокого уровня, L4 — uLang. Статус: план (Этап 6).
- Библиотеки и приложения, L5+ — uStd, графика, игра. Статус: план.

ПРАВИЛА ЗАВИСИМОСТЕЙ

- Слой может использовать только нижележащие слои.
- Код слоёв L* не использует T*-инструменты (те лишь строят и
  проверяют слои L*).
- T*-инструменты временные: при самохостинге заменяются на собственные
  и удаляются.

ВЕТВИ КОДА

Ветвь — дерево вызовов одного метода: сложный метод состоит из менее
сложных, те — из ещё более простых, и так до предела простоты.

Имя ветви: <слой>.<подсистема>.<модуль>, например t0.infra.registry;
будущие: t0.uvm.core (Python-эталон UVM, Этап 1), l2.asm.parser.

Свойства ветвей:

- изоляция: ветвь не обращается к внутренностям чужих ветвей, только
  к их опубликованным методам, описанным карточками;
- локальность: чтобы изменить одно место кода, достаточно прочитать
  карточки методов одной ветви (см. registry/) и спецификацию её
  слоя;
- явность: зависимости метода перечислены в карточке (@depends).

Замечание о двойных воплощениях: Python-эталон UVM живёт в ветвях
t0.uvm.*; при самохостинге (Этап 4) те же подсистемы будут переписаны
на собственном коде и получат ветви l1.uvm.*.

РАЗМЕЩЕНИЕ В РЕПОЗИТОРИИ

- SPEC/ — спецификации слоёв, по одному файлу на слой (.txt).
- DOC/ — карта документов: архитектура, конвенции, протокол
  продолжения (.txt).
- tools/ — бустрап-инструменты (T0): реестр, проверки, будущие
  эмулятор и ассемблер.
- src/ — исходники слоёв L2+ (.uasm, .ubrk, затем uLang; есть
  с Этапа 2).
- tests/ — тесты; тесты ветви живут в её файлах test_*.py.
- registry/ — генерируемый реестр: индекс METHODS.txt + карточки
  по исходным файлам registry/<ветвь>/<файл>.txt.
